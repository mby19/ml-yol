Random Variables

In (see related section) we saw the basics of how to work with discrete random variables, which in our case refer to those random variables which take either a finite set of possible values, or the integers. In this section, we develop the theory of continuous random variables, which are random variables which can take on any real value.

Continuous Random Variables

Continuous random variables are a significantly more subtle topic than discrete random variables. A fair analogy to make is that the technical jump is comparable to the jump between adding lists of numbers and integrating functions. As such, we will need to take some time to develop the theory.

From Discrete to Continuous

To understand the additional technical challenges encountered when working with continuous random variables, let's perform a thought experiment. Suppose that we are throwing a dart at the dart board, and we want to know the probability that it hits exactly 2cm2 \textrm{cm}2cm from the center of the board.

To start with, we imagine measuring a single digit of accuracy, that is to say with bins for 0cm0 \textrm{cm}0cm, 1cm1 \textrm{cm}1cm, 2cm2 \textrm{cm}2cm, and so on. We throw say 100100100 darts at the dart board, and if 202020 of them fall into the bin for 2cm2\textrm{cm}2cm we conclude that 20%20\%20% of the darts we throw hit the board 2cm2 \textrm{cm}2cm away from the center.

However, when we look closer, this does not match our question! We wanted exact equality, whereas these bins hold all that fell between say 1.5cm1.5\textrm{cm}1.5cm and 2.5cm2.5\textrm{cm}2.5cm.

Undeterred, we continue further. We measure even more precisely, say 1.9cm1.9\textrm{cm}1.9cm, 2.0cm2.0\textrm{cm}2.0cm, 2.1cm2.1\textrm{cm}2.1cm, and now see that perhaps 333 of the 100100100 darts hit the board in the 2.0cm2.0\textrm{cm}2.0cm bucket. Thus we conclude the probability is 3%3\%3%.

However, this does not solve anything! We have just pushed the issue down one digit further. Let's abstract a bit. Imagine we know the probability that the first kkk digits match with 2.00000…2.00000\ldots2.00000… and we want to know the probability it matches for the first k+1k+1k+1 digits. It is fairly reasonable to assume that the k+1th{k+1}^{\textrm{th}}k+1th digit is essentially a random choice from the set {0,1,2,…,9}\{0, 1, 2, \ldots, 9\}{0,1,2,…,9}. At least, we cannot conceive of a physically meaningful process which would force the number of micrometers away form the center to prefer to end in a 777 vs a 333.

What this means is that in essence each additional digit of accuracy we require should decrease probability of matching by a factor of 101010. Or put another way, we would expect that

P(distance is  2.00…,  to  k  digits)≈p⋅10−k.P(\textrm{distance is}\; 2.00\ldots, \;\textrm{to}\; k \;\textrm{digits} ) \approx p\cdot10^{-k}.P(distance is2.00…,tokdigits)≈p⋅10−k.

The value ppp essentially encodes what happens with the first few digits, and the 10−k10^{-k}10−k handles the rest.

Notice that if we know the position accurate to k=4k=4k=4 digits after the decimal, that means we know the value falls within the interval say [1.99995,2.00005][1.99995,2.00005][1.99995,2.00005] which is an interval of length 2.00005−1.99995=10−42.00005-1.99995 = 10^{-4}2.00005−1.99995=10−4. Thus, if we call the length of this interval ϵ\epsilonϵ, we can say

P(distance is in an  ϵ-sized interval around  2)≈ϵ⋅p.P(\textrm{distance is in an}\; \epsilon\textrm{-sized interval around}\; 2 ) \approx \epsilon \cdot p.P(distance is in anϵ-sized interval around2)≈ϵ⋅p.

Let's take this one final step further. We have been thinking about the point 222 the entire time, but never thinking about other points. Nothing is different there fundamentally, but it is the case that the value ppp will likely be different. We would at least hope that a dart thrower was more likely to hit a point near the center, like 2cm2\textrm{cm}2cm rather than 20cm20\textrm{cm}20cm. Thus, the value ppp is not fixed, but rather should depend on the point xxx. This tells us that we should expect

P(distance is in an  ϵ-sized interval around  x)≈ϵ⋅p(x).P(\textrm{distance is in an}\; \epsilon \textrm{-sized interval around}\; x ) \approx \epsilon \cdot p(x).P(distance is in anϵ-sized interval aroundx)≈ϵ⋅p(x). Indeed, (see equation above) precisely defines the probability density function. It is a function p(x)p(x)p(x) which encodes the relative probability of hitting near one point vs. another. Let's visualize what such a function might look like.

Probability Density Functions

Let's now investigate this further. We have already seen what a probability density function is intuitively for a random variable XXX, namely the density function is a function p(x)p(x)p(x) so that

P(X  is in an  ϵ-sized interval around  x)≈ϵ⋅p(x).P(X \; \textrm{is in an}\; \epsilon \textrm{-sized interval around}\; x ) \approx \epsilon \cdot p(x).P(Xis in anϵ-sized interval aroundx)≈ϵ⋅p(x). But what does this imply for the properties of p(x)p(x)p(x)?

First, probabilities are never negative, thus we should expect that p(x)≥0p(x) \ge 0p(x)≥0 as well.

Second, let's imagine that we slice up the R\mathbb{R}R into an infinite number of slices which are ϵ\epsilonϵ wide, say with slices (ϵ⋅i,ϵ⋅(i+1)](\epsilon\cdot i, \epsilon \cdot (i+1)](ϵ⋅i,ϵ⋅(i+1)]. For each of these, we know from (see equation above) the probability is approximately

P(X  is in an  ϵ-sized interval around  x)≈ϵ⋅p(ϵ⋅i),P(X \; \textrm{is in an}\; \epsilon\textrm{-sized interval around}\; x ) \approx \epsilon \cdot p(\epsilon \cdot i),P(Xis in anϵ-sized interval aroundx)≈ϵ⋅p(ϵ⋅i),

so summed over all of them it should be

P(X∈R)≈∑iϵ⋅p(ϵ⋅i).P(X\in\mathbb{R}) \approx \sum_i \epsilon \cdot p(\epsilon\cdot i).P(X∈R)≈i∑​ϵ⋅p(ϵ⋅i).

This is nothing more than the approximation of an integral discussed in (see related section), thus we can say that

P(X∈R)=∫−∞∞p(x)  dx.P(X\in\mathbb{R}) = \int_{-\infty}^{\infty} p(x) \; dx.P(X∈R)=∫−∞∞​p(x)dx.

We know that P(X∈R)=1P(X\in\mathbb{R}) = 1P(X∈R)=1, since the random variable must take on some number, we can conclude that for any density

∫−∞∞p(x)  dx=1.\int_{-\infty}^{\infty} p(x) \; dx = 1.∫−∞∞​p(x)dx=1.

Indeed, digging into this further shows that for any aaa, and bbb, we see that

P(X∈(a,b])=∫abp(x)  dx.P(X\in(a, b]) = \int _ {a}^{b} p(x) \; dx.P(X∈(a,b])=∫ab​p(x)dx.

We may approximate this in code by using the same discrete approximation methods as before. In this case we can approximate the probability of falling in the blue region.

It turns out that these two properties describe exactly the space of possible probability density functions (or p.d.f.'s for the commonly encountered abbreviation). They are non-negative functions p(x)≥0p(x) \ge 0p(x)≥0 such that

∫−∞∞p(x)  dx=1.\int_{-\infty}^{\infty} p(x) \; dx = 1.∫−∞∞​p(x)dx=1. We interpret this function by using integration to obtain the probability our random variable is in a specific interval:

P(X∈(a,b])=∫abp(x)  dx.P(X\in(a, b]) = \int _ {a}^{b} p(x) \; dx.P(X∈(a,b])=∫ab​p(x)dx. In (see related section) we will see a number of common distributions, but let's continue working in the abstract.

Cumulative Distribution Functions

In the previous section, we saw the notion of the p.d.f. In practice, this is a commonly encountered method to discuss continuous random variables, but it has one significant pitfall: that the values of the p.d.f. are not themselves probabilities, but rather a function that we must integrate to yield probabilities. There is nothing wrong with a density being larger than 101010, as long as it is not larger than 101010 for more than an interval of length 1/101/101/10. This can be counter-intuitive, so people often also think in terms of the cumulative distribution function, or c.d.f., which is a probability.

In particular, by using (see equation above), we define the c.d.f. for a random variable XXX with density p(x)p(x)p(x) by

F(x)=∫−∞xp(x)  dx=P(X≤x).F(x) = \int _ {-\infty}^{x} p(x) \; dx = P(X \le x).F(x)=∫−∞x​p(x)dx=P(X≤x).

Let's observe a few properties.

  • F(x)→0F(x) \rightarrow 0F(x)→0 as x→−∞x\rightarrow -\inftyx→−∞.
  • F(x)→1F(x) \rightarrow 1F(x)→1 as x→∞x\rightarrow \inftyx→∞.
  • F(x)F(x)F(x) is non-decreasing (y>x  ⟹  F(y)≥F(x)y > x \implies F(y) \ge F(x)y>x⟹F(y)≥F(x)).
  • F(x)F(x)F(x) is continuous (has no jumps) if XXX is a continuous random variable.

With the fourth bullet point, note that this would not be true if XXX were discrete, say taking the values 000 and 111 both with probability 1/21/21/2. In that case

F(x)={0x<0,12x<1,1x≥1.F(x) = \begin{cases} 0 & x < 0, \\ \frac{1}{2} & x < 1, \\ 1 & x \ge 1. \end{cases}F(x)=⎩⎨⎧​021​1​x<0,x<1,x≥1.​

In this example, we see one of the benefits of working with the c.d.f., the ability to deal with continuous or discrete random variables in the same framework, or indeed mixtures of the two (flip a coin: if heads return the roll of a die, if tails return the distance of a dart throw from the center of a dart board).

Means

Suppose that we are dealing with a random variables XXX. The distribution itself can be hard to interpret. It is often useful to be able to summarize the behavior of a random variable concisely. Numbers that help us capture the behavior of a random variable are called summary statistics. The most commonly encountered ones are the mean, the variance, and the standard deviation.

The mean encodes the average value of a random variable. If we have a discrete random variable XXX, which takes the values xix_ixi​ with probabilities pip_ipi​, then the mean is given by the weighted average: sum the values times the probability that the random variable takes on that value:

μX=E[X]=∑ixipi.\mu_X = E[X] = \sum_i x_i p_i.μX​=E[X]=∑i​xi​pi​. The way we should interpret the mean (albeit with caution) is that it tells us essentially where the random variable tends to be located.

As a minimalistic example that we will examine throughout this section, let's take XXX to be the random variable which takes the value a−2a-2a−2 with probability ppp, a+2a+2a+2 with probability ppp and aaa with probability 1−2p1-2p1−2p. We can compute using (see equation above) that, for any possible choice of aaa and ppp, the mean is

μX=E[X]=∑ixipi=(a−2)p+a(1−2p)+(a+2)p=a.\mu_X = E[X] = \sum_i x_i p_i = (a-2)p + a(1-2p) + (a+2)p = a.μX​=E[X]=i∑​xi​pi​=(a−2)p+a(1−2p)+(a+2)p=a.

Thus we see that the mean is aaa. This matches the intuition since aaa is the location around which we centered our random variable.

Because they are helpful, let's summarize a few properties.

  • For any random variable XXX and numbers aaa and bbb, we have that μaX+b=aμX+b\mu_{aX+b} = a\mu_X + bμaX+b​=aμX​+b.
  • If we have two random variables XXX and YYY, we have μX+Y=μX+μY\mu_{X+Y} = \mu_X+\mu_YμX+Y​=μX​+μY​.

Means are useful for understanding the average behavior of a random variable, however the mean is not sufficient to even have a full intuitive understanding. Making a profit of \textdollar10±\textdollar1\textdollar{}10 \pm \textdollar{}1\textdollar10±\textdollar1 per sale is very different from making \textdollar10±\textdollar15\textdollar{}10 \pm \textdollar{}15\textdollar10±\textdollar15 per sale despite having the same average value. The second one has a much larger degree of fluctuation, and thus represents a much larger risk. Thus, to understand the behavior of a random variable, we will need at minimum one more measure: some measure of how widely a random variable fluctuates.

Variances

This leads us to consider the variance of a random variable. This is a quantitative measure of how far a random variable deviates from the mean. Consider the expression X−μXX - \mu_XX−μX​. This is the deviation of the random variable from its mean. This value can be positive or negative, so we need to do something to make it positive so that we are measuring the magnitude of the deviation.

A reasonable thing to try is to look at ∣X−μX∣\left|X-\mu_X\right|∣X−μX​∣, and indeed this leads to a useful quantity called the mean absolute deviation, however due to connections with other areas of mathematics and statistics, people often use a different solution.

In particular, they look at (X−μX)2.(X-\mu_X)^2.(X−μX​)2. If we look at the typical size of this quantity by taking the mean, we arrive at the variance

σX2=Var(X)=E[(X−μX)2]=E[X2]−μX2.\sigma_X^2 = \textrm{Var}(X) = E\left[(X-\mu_X)^2\right] = E[X^2] - \mu_X^2.σX2​=Var(X)=E[(X−μX​)2]=E[X2]−μX2​. The last equality in (see equation above) holds by expanding out the definition in the middle, and applying the properties of expectation.

Let's look at our example where XXX is the random variable which takes the value a−2a-2a−2 with probability ppp, a+2a+2a+2 with probability ppp and aaa with probability 1−2p1-2p1−2p. In this case μX=a\mu_X = aμX​=a, so all we need to compute is E[X2]E\left[X^2\right]E[X2]. This can readily be done:

E[X2]=(a−2)2p+a2(1−2p)+(a+2)2p=a2+8p.E\left[X^2\right] = (a-2)^2p + a^2(1-2p) + (a+2)^2p = a^2 + 8p.E[X2]=(a−2)2p+a2(1−2p)+(a+2)2p=a2+8p.

Thus, we see that by (see equation above) our variance is

σX2=Var(X)=E[X2]−μX2=a2+8p−a2=8p.\sigma_X^2 = \textrm{Var}(X) = E[X^2] - \mu_X^2 = a^2 + 8p - a^2 = 8p.σX2​=Var(X)=E[X2]−μX2​=a2+8p−a2=8p.

This result again makes sense. The largest ppp can be is 1/21/21/2 which corresponds to picking a−2a-2a−2 or a+2a+2a+2 with a coin flip. The variance of this being 444 corresponds to the fact that both a−2a-2a−2 and a+2a+2a+2 are 222 units away from the mean, and 22=42^2 = 422=4. On the other end of the spectrum, if p=0p=0p=0, this random variable always takes the value 000 and so it has no variance at all.

We will list a few properties of variance below:

  • For any random variable XXX, Var(X)≥0\textrm{Var}(X) \ge 0Var(X)≥0, with Var(X)=0\textrm{Var}(X) = 0Var(X)=0 if and only if XXX is a constant.
  • For any random variable XXX and numbers aaa and bbb, we have that Var(aX+b)=a2Var(X)\textrm{Var}(aX+b) = a^2\textrm{Var}(X)Var(aX+b)=a2Var(X).
  • If we have two independent random variables XXX and YYY, we have Var(X+Y)=Var(X)+Var(Y)\textrm{Var}(X+Y) = \textrm{Var}(X) + \textrm{Var}(Y)Var(X+Y)=Var(X)+Var(Y).

When interpreting these values, there can be a bit of a hiccup. In particular, let's try imagining what happens if we keep track of units through this computation. Suppose that we are working with the star rating assigned to a product on the web page. Then aaa, a−2a-2a−2, and a+2a+2a+2 are all measured in units of stars. Similarly, the mean μX\mu_XμX​ is then also measured in stars (being a weighted average). However, if we get to the variance, we immediately encounter an issue, which is we want to look at (X−μX)2(X-\mu_X)^2(X−μX​)2, which is in units of squared stars. This means that the variance itself is not comparable to the original measurements. To make it interpretable, we will need to return to our original units.

Standard Deviations

This summary statistics can always be deduced from the variance by taking the square root! Thus we define the standard deviation to be

σX=Var(X).\sigma_X = \sqrt{\textrm{Var}(X)}.σX​=Var(X)​.

In our example, this means we now have the standard deviation is σX=22p\sigma_X = 2\sqrt{2p}σX​=22p​. If we are dealing with units of stars for our review example, σX\sigma_XσX​ is again in units of stars.

The properties we had for the variance can be restated for the standard deviation.

  • For any random variable XXX, σX≥0\sigma_{X} \ge 0σX​≥0.
  • For any random variable XXX and numbers aaa and bbb, we have that σaX+b=∣a∣σX\sigma_{aX+b} = |a|\sigma_{X}σaX+b​=∣a∣σX​
  • If we have two independent random variables XXX and YYY, we have σX+Y=σX2+σY2\sigma_{X+Y} = \sqrt{\sigma_{X}^2 + \sigma_{Y}^2}σX+Y​=σX2​+σY2​​.

It is natural at this moment to ask, "If the standard deviation is in the units of our original random variable, does it represent something we can draw with regards to that random variable?" The answer is a resounding yes! Indeed much like the mean told us the typical location of our random variable, the standard deviation gives the typical range of variation of that random variable. We can make this rigorous with what is known as Chebyshev's inequality:

P(X∉[μX−ασX,μX+ασX])≤1α2.P\left(X \not\in [\mu_X - \alpha\sigma_X, \mu_X + \alpha\sigma_X]\right) \le \frac{1}{\alpha^2}.P(X∈[μX​−ασX​,μX​+ασX​])≤α21​. Or to state it verbally in the case of α=10\alpha=10α=10, 99%99\%99% of the samples from any random variable fall within 101010 standard deviations of the mean. This gives an immediate interpretation to our standard summary statistics.

To see how this statement is rather subtle, let's take a look at our running example again where XXX is the random variable which takes the value a−2a-2a−2 with probability ppp, a+2a+2a+2 with probability ppp and aaa with probability 1−2p1-2p1−2p. We saw that the mean was aaa and the standard deviation was 22p2\sqrt{2p}22p​. This means, if we take Chebyshev's inequality (see equation above) with α=2\alpha = 2α=2, we see that the expression is

P(X∉[a−42p,a+42p])≤14.P\left(X \not\in [a - 4\sqrt{2p}, a + 4\sqrt{2p}]\right) \le \frac{1}{4}.P(X∈[a−42p​,a+42p​])≤41​.

This means that 75%75\%75% of the time, this random variable will fall within this interval for any value of ppp. Now, notice that as p→0p \rightarrow 0p→0, this interval also converges to the single point aaa. But we know that our random variable takes the values a−2,aa-2, aa−2,a, and a+2a+2a+2 only so eventually we can be certain a−2a-2a−2 and a+2a+2a+2 will fall outside the interval! The question is, at what ppp does that happen. So we want to solve: for what ppp does a+42p=a+2a+4\sqrt{2p} = a+2a+42p​=a+2, which is solved when p=1/8p=1/8p=1/8, which is exactly the first ppp where it could possibly happen without violating our claim that no more than 1/41/41/4 of samples from the distribution would fall outside the interval (1/81/81/8 to the left, and 1/81/81/8 to the right).

Let's visualize this. We will show the probability of getting the three values as three vertical bars with height proportional to the probability. The interval will be drawn as a horizontal line in the middle. The first plot shows what happens for p>1/8p > 1/8p>1/8 where the interval safely contains all points.

Means and Variances in the Continuum

This has all been in terms of discrete random variables, but the case of continuous random variables is similar. To intuitively understand how this works, imagine that we split the real number line into intervals of length ϵ\epsilonϵ given by (ϵi,ϵ(i+1)](\epsilon i, \epsilon (i+1)](ϵi,ϵ(i+1)]. Joint Density Functions

The above work all assumes we are working with a single real valued random variable. But what if we are dealing with two or more potentially highly correlated random variables? Marginal Distributions

When dealing with multiple variables, we oftentimes want to be able to ignore the relationships and ask, "how is this one variable distributed?" Such a distribution is called a marginal distribution.

When dealing with multiple random variables, there is one additional summary statistic which is helpful to know: the covariance. This measures the degree that two random variable fluctuate together.

Correlation

As we did in the case of means and variances, let's now consider units. If XXX is measured in one unit (say inches), and YYY is measured in another (say dollars), the covariance is measured in the product of these two units inches×dollars\textrm{inches} \times \textrm{dollars}inches×dollars. These units can be hard to interpret. What we will often want in this case is a unit-less measurement of relatedness. Indeed, often we do not care about exact quantitative correlation, but rather ask if the correlation is in the same direction, and how strong the relationship is.

To see what makes sense, let's perform a thought experiment. Suppose that we convert our random variables in inches and dollars to be in inches and cents. In this case the random variable YYY is multiplied by 100100100. If we work through the definition, this means that Cov(X,Y)\textrm{Cov}(X, Y)Cov(X,Y) will be multiplied by 100100100. Thus we see that in this case a change of units change the covariance by a factor of 100100100. Thus, to find our unit-invariant measure of correlation, we will need to divide by something else that also gets scaled by 100100100. Indeed we have a clear candidate, the standard deviation! Indeed if we define the correlation coefficient to be

A little mathematics can show that this number is between −1-1−1 and 111 with 111 meaning maximally positively correlated, whereas −1-1−1 means maximally negatively correlated.

Returning to our explicit discrete example above, we can see that σX=1\sigma_X = 1σX​=1 and σY=2\sigma_Y = 2σY​=2, so we can compute the correlation between the two random variables using (see equation above) to see that

This now ranges between −1-1−1 and 111 with the expected behavior of 111 meaning most correlated, and −1-1−1 meaning minimally correlated.

Summary

  • Continuous random variables are random variables that can take on a continuum of values. They have some technical difficulties that make them more challenging to work with compared to discrete random variables.
  • The probability density function allows us to work with continuous random variables by giving a function where the area under the curve on some interval gives the probability of finding a sample point in that interval.
  • The cumulative distribution function is the probability of observing the random variable to be less than a given threshold. It can provide a useful alternate viewpoint which unifies discrete and continuous variables.
  • The mean is the average value of a random variable.
  • The variance is the expected square of the difference between the random variable and its mean.
  • The standard deviation is the square root of the variance. It can be thought of as measuring the range of values the random variable may take.
  • Chebyshev's inequality allows us to make this intuition rigorous by giving an explicit interval that contains the random variable most of the time.
  • Joint densities allow us to work with correlated random variables. We may marginalize joint densities by integrating over unwanted random variables to get the distribution of the desired random variable.
  • The covariance and correlation coefficient provide a way to measure any linear relationship between two correlated random variables.
