Single Variable Calculus

In (see related section), we saw the basic elements of differential calculus. This section takes a deeper dive into the fundamentals of calculus and how we can understand and apply it in the context of machine learning.

Kod02 / 09

Differential Calculus

Differential calculus is fundamentally the study of how functions behave under small changes. To see why this is so core to deep learning, let's consider an example.

Suppose that we have a deep neural network where the weights are, for convenience, concatenated into a single vector w=(w1,…,wn)\mathbf{w} = (w_1, \ldots, w_n)w=(w1​,…,wn​). Given a training dataset, we consider the loss of our neural network on this dataset, which we will write as L(w)\mathcal{L}(\mathbf{w})L(w).

This function is extraordinarily complex, encoding the performance of all possible models of the given architecture on this dataset, so it is nearly impossible to tell what set of weights w\mathbf{w}w will minimize the loss. Thus, in practice, we often start by initializing our weights randomly, and then iteratively take small steps in the direction which makes the loss decrease as rapidly as possible.

The question then becomes something that on the surface is no easier: how do we find the direction which makes the weights decrease as quickly as possible? To dig into this, let's first examine the case with only a single weight: L(w)=L(x)L(\mathbf{w}) = L(x)L(w)=L(x) for a single real value xxx.

Let's take xxx and try to understand what happens when we change it by a small amount to x+ϵx + \epsilonx+ϵ. If you wish to be concrete, think a number like ϵ=0.0000001\epsilon = 0.0000001ϵ=0.0000001. To help us visualize what happens, let's graph an example function, f(x)=sin⁡(xx)f(x) = \sin(x^x)f(x)=sin(xx), over the [0,3][0, 3][0,3].

At this large scale, the function's behavior is not simple. However, if we reduce our range to something smaller like [1.75,2.25][1.75,2.25][1.75,2.25], we see that the graph becomes much simpler.

Taking this to an extreme, if we zoom into a tiny segment, the behavior becomes far simpler: it is just a straight line.

This is the key observation of single variable calculus: the behavior of familiar functions can be modeled by a line in a small enough range. This means that for most functions, it is reasonable to expect that as we shift the xxx value of the function by a little bit, the output f(x)f(x)f(x) will also be shifted by a little bit. The only question we need to answer is, "How large is the change in the output compared to the change in the input? Is it half as large? Twice as large?"

Thus, we can consider the ratio of the change in the output of a function for a small change in the input of the function. We can write this formally as

L(x+ϵ)−L(x)(x+ϵ)−x=L(x+ϵ)−L(x)ϵ.\frac{L(x+\epsilon) - L(x)}{(x+\epsilon) - x} = \frac{L(x+\epsilon) - L(x)}{\epsilon}.(x+ϵ)−xL(x+ϵ)−L(x)​=ϵL(x+ϵ)−L(x)​.

This is already enough to start to play around with in code. For instance, suppose that we know that L(x)=x2+1701(x−4)3L(x) = x^{2} + 1701(x-4)^3L(x)=x2+1701(x−4)3, then we can see how large this value is at the point x=4x = 4x=4 as follows.

# Define our function
def L(x):
    return x**2 + 1701*(x-4)**3

# Print the difference divided by epsilon for several epsilon
for epsilon in [0.1, 0.001, 0.0001, 0.00001]:
    print(f'epsilon = {epsilon:.5f} -> {(L(4+epsilon) - L(4)) / epsilon:.5f}')

Now, if we are observant, we will notice that the output of this number is suspiciously close to 888. Indeed, if we decrease ϵ\epsilonϵ, we will see value becomes progressively closer to 888. Thus we may conclude, correctly, that the value we seek (the degree a change in the input changes the output) should be 888 at the point x=4x=4x=4. The way that a mathematician encodes this fact is

lim⁡ϵ→0L(4+ϵ)−L(4)ϵ=8.\lim_{\epsilon \rightarrow 0}\frac{L(4+\epsilon) - L(4)}{\epsilon} = 8.ϵ→0lim​ϵL(4+ϵ)−L(4)​=8.

As a bit of a historical digression: in the first few decades of neural network research, scientists used this algorithm (the method of finite differences) to evaluate how a loss function changed under small perturbation: just change the weights and see how the loss changed. This is computationally inefficient, requiring two evaluations of the loss function to see how a single change of one variable influenced the loss. If we tried to do this with even a paltry few thousand parameters, it would require several thousand evaluations of the network over the entire dataset! It was not solved until 1986 that the backpropagation algorithm introduced in (Rumelhart et al.) provided a way to calculate how any change of the weights together would change the loss in the same computation time as a single prediction of the network over the dataset.

Back in our example, this value 888 is different for different values of xxx, so it makes sense to define it as a function of xxx. More formally, this value dependent rate of change is referred to as the derivative which is written as

dfdx(x)=lim⁡ϵ→0f(x+ϵ)−f(x)ϵ.\frac{df}{dx}(x) = \lim_{\epsilon \rightarrow 0}\frac{f(x+\epsilon) - f(x)}{\epsilon}.dxdf​(x)=limϵ→0​ϵf(x+ϵ)−f(x)​. Different texts will use different notations for the derivative. For instance, all of the below notations indicate the same thing:

dfdx=ddxf=f′=∇xf=Dxf=fx.\frac{df}{dx} = \frac{d}{dx}f = f' = \nabla_xf = D_xf = f_x.dxdf​=dxd​f=f′=∇x​f=Dx​f=fx​.

Most authors will pick a single notation and stick with it, however even that is not guaranteed. It is best to be familiar with all of these. We will use the notation dfdx\frac{df}{dx}dxdf​ throughout this text, unless we want to take the derivative of a complex expression, in which case we will use ddxf\frac{d}{dx}fdxd​f to write expressions like

ddx[x4+cos⁡(x2+12x−1)].\frac{d}{dx}\left[x^4+\cos\left(\frac{x^2+1}{2x-1}\right)\right].dxd​[x4+cos(2x−1x2+1​)].

Oftentimes, it is intuitively useful to unravel the definition of derivative (see equation above) again to see how a function changes when we make a small change of xxx:

It tells us that if you take any function and change the input by a small amount, the output would change by that small amount scaled by the derivative.

In this way, we can understand the derivative as the scaling factor that tells us how large of change we get in the output from a change in the input.

Rules of Calculus

We now turn to the task of understanding how to compute the derivative of an explicit function. A full formal treatment of calculus would derive everything from first principles. We will not indulge in this temptation here, but rather provide an understanding of the common rules encountered.

Common Derivatives

As was seen in (see related section), when computing derivatives one can oftentimes use a series of rules to reduce the computation to a few core functions. We repeat them here for ease of reference.

  • Derivative of constants. ddxc=0\frac{d}{dx}c = 0dxd​c=0.
  • Derivative of linear functions. ddx(ax)=a\frac{d}{dx}(ax) = adxd​(ax)=a.
  • Power rule. ddxxn=nxn−1\frac{d}{dx}x^n = nx^{n-1}dxd​xn=nxn−1.
  • Derivative of exponentials. ddxex=ex\frac{d}{dx}e^x = e^xdxd​ex=ex.
  • Derivative of the logarithm. ddxlog⁡(x)=1x\frac{d}{dx}\log(x) = \frac{1}{x}dxd​log(x)=x1​.

If every derivative needed to be separately computed and stored in a table, differential calculus would be near impossible.   2. Having a human follow these rules can be tedious and error prone!

Thankfully, these two facts together hint towards a way forward: this is a perfect candidate for mechanization! Indeed backpropagation, which we will revisit later in this section, is exactly that.

Linear Approximation

When working with derivatives, it is often useful to geometrically interpret the approximation used above. In particular, note that the equation

f(x+ϵ)≈f(x)+ϵdfdx(x),f(x+\epsilon) \approx f(x) + \epsilon \frac{df}{dx}(x),f(x+ϵ)≈f(x)+ϵdxdf​(x),

approximates the value of fff by a line which passes through the point (x,f(x))(x, f(x))(x,f(x)) and has slope dfdx(x)\frac{df}{dx}(x)dxdf​(x). In this way we say that the derivative gives a linear approximation to the function fff, as illustrated below:

# Compute sin
xs = torch.arange(-torch.pi, torch.pi, 0.01)
plots = [torch.sin(xs)]

# Compute some linear approximations. Use d(sin(x))/dx = cos(x)
for x0 in [-1.5, 0.0, 2.0]:

                 torch.cos(torch.tensor(x0)))

d2l.plot(xs, plots, 'x', 'f(x)', ylim=[-1.5, 1.5])

Higher Order Derivatives

Let's now do something that may on the surface seem strange. Take a function fff and compute the derivative dfdx\frac{df}{dx}dxdf​. This gives us the rate of change of fff at any point.

However, the derivative, dfdx\frac{df}{dx}dxdf​, can be viewed as a function itself, so nothing stops us from computing the derivative of dfdx\frac{df}{dx}dxdf​ to get d2fdx2=dfdx(dfdx)\frac{d^2f}{dx^2} = \frac{df}{dx}\left(\frac{df}{dx}\right)dx2d2f​=dxdf​(dxdf​). We will call this the second derivative of fff. This function is the rate of change of the rate of change of fff, or in other words, how the rate of change is changing. We may apply the derivative any number of times to obtain what is called the nnn-th derivative. To keep the notation clean, we will denote the nnn-th derivative as

f(n)(x)=dnfdxn=(ddx)nf.f^{(n)}(x) = \frac{d^{n}f}{dx^{n}} = \left(\frac{d}{dx}\right)^{n} f.f(n)(x)=dxndnf​=(dxd​)nf.

Let's try to understand why this is a useful notion. Below, we visualize f(2)(x)f^{(2)}(x)f(2)(x), f(1)(x)f^{(1)}(x)f(1)(x), and f(x)f(x)f(x).

First, consider the case that the second derivative f(2)(x)f^{(2)}(x)f(2)(x) is a positive constant. This means that the slope of the first derivative is positive. As a result, the first derivative f(1)(x)f^{(1)}(x)f(1)(x) may start out negative, becomes zero at a point, and then becomes positive in the end. This tells us the slope of our original function fff and therefore, the function fff itself decreases, flattens out, then increases. In other words, the function fff curves up, and has a single minimum as is shown in (see related section).

Şekil: If we assume the second derivative is a positive constant, then the fist derivative in increasing, which implies the function itself has a minimum. Second, if the second derivative is a negative constant, that means that the first derivative is decreasing. This implies the first derivative may start out positive, becomes zero at a point, and then becomes negative. Hence, the function fff itself increases, flattens out, then decreases. In other words, the function fff curves down, and has a single maximum as is shown in (see related section).

Şekil: If we assume the second derivative is a negative constant, then the fist derivative in decreasing, which implies the function itself has a maximum. Third, if the second derivative is a always zero, then the first derivative will never change---it is constant! This means that fff increases (or decreases) at a fixed rate, and fff is itself a straight line as is shown in (see related section).

Şekil: If we assume the second derivative is zero, then the fist derivative is constant, which implies the function itself is a straight line. To summarize, the second derivative can be interpreted as describing the way that the function fff curves. A positive second derivative leads to a upwards curve, while a negative second derivative means that fff curves downwards, and a zero second derivative means that fff does not curve at all.

Let's take this one step further. Consider the function g(x)=ax2+bx+cg(x) = ax^{2}+ bx + cg(x)=ax2+bx+c. We can then compute that

dgdx(x)=2ax+bd2gdx2(x)=2a.\begin{aligned} \frac{dg}{dx}(x) & = 2ax + b \\ \frac{d^2g}{dx^2}(x) & = 2a. \end{aligned}dxdg​(x)dx2d2g​(x)​=2ax+b=2a.​

If we have some original function f(x)f(x)f(x) in mind, we may compute the first two derivatives and find the values for a,ba, ba,b, and ccc that make them match this computation. Similarly to the previous section where we saw that the first derivative gave the best approximation with a straight line, this construction provides the best approximation by a quadratic. Let's visualize this for f(x)=sin⁡(x)f(x) = \sin(x)f(x)=sin(x).

Taylor Series

The Taylor series provides a method to approximate the function f(x)f(x)f(x) if we are given values for the first nnn derivatives at a point x0x_0x0​, i.e., {f(x0),f(1)(x0),f(2)(x0),…,f(n)(x0)}\left\{ f(x_0), f^{(1)}(x_0), f^{(2)}(x_0), \ldots, f^{(n)}(x_0) \right\}{f(x0​),f(1)(x0​),f(2)(x0​),…,f(n)(x0​)}. While we are not going to dive all the way into the error of the above approximations, it is worth mentioning the infinite limit. In this case, for well behaved functions (known as real analytic functions) like cos⁡(x)\cos(x)cos(x) or exe^{x}ex, we can write out the infinite number of terms and approximate the exactly same function

Let's see how this works in code and observe how increasing the degree of the Taylor approximation brings us closer to the desired function exe^xex.

# Compute the exponential function
xs = torch.arange(0, 3, 0.01)
ys = torch.exp(xs)

# Compute a few Taylor series approximations
P1 = 1 + xs
P2 = 1 + xs + xs**2 / 2
P5 = 1 + xs + xs**2 / 2 + xs**3 / 6 + xs**4 / 24 + xs**5 / 120

d2l.plot(xs, [ys, P1, P2, P5], 'x', 'f(x)', legend=[
    "Exponential", "Degree 1 Taylor Series", "Degree 2 Taylor Series",
    "Degree 5 Taylor Series"])

Taylor series have two primary applications:

  1. Theoretical applications: Often when we try to understand a too complex function, using Taylor series enables us to turn it into a polynomial that we can work with directly.

  2. Numerical applications: Some functions like exe^{x}ex or cos⁡(x)\cos(x)cos(x) are difficult for machines to compute. They can store tables of values at a fixed precision (and this is often done), but it still leaves open questions like "What is the 1000-th digit of cos⁡(1)\cos(1)cos(1)?" Taylor series are often helpful to answer such questions.

Summary

  • Derivatives can be used to express how functions change when we change the input by a small amount.
  • Elementary derivatives can be combined using derivative rules to create arbitrarily complex derivatives.
  • Derivatives can be iterated to get second or higher order derivatives. Each increase in order provides more fine grained information on the behavior of the function.
  • Using information in the derivatives of a single data example, we can approximate well behaved functions by polynomials obtained from the Taylor series.
