Kısıtlı optimizasyon: kurallara uyarak en iyiyi bulmak

Şimdiye kadar parametreler istediği yere gidebiliyordu. Gerçek problemlerde çoğu zaman kısıt vardır:

  • Bütçe: reklam harcamaları toplamı 100 bin TL'yi geçemez.
  • Olasılıklar: bir dağılımın değerleri toplamı 1 olmalı.
  • SVM: her eğitim noktası karar sınırının doğru tarafında, en az belli bir mesafede olmalı.

Bu ders kısa ve sezgi odaklı: amacın, SVM'i ve "KL-kısıtlı" yöntemleri okurken Lagrange çarpanlarını tanıyabilmek. Problem tipi kısıtlı optimizasyon:

min⁡x f(x)kos¸uluylag(x)=0\min_{x}\ f(x) \quad \text{koşuluyla} \quad g(x) = 0xmin​ f(x)kos¸​uluylag(x)=0

Geometrik sezgi: teğet olma anı

Örnek: f(x,y)=x2+y2f(x, y) = x^2 + y^2f(x,y)=x2+y2'yi (orijine uzaklığın karesi) en küçük yap, ama x+y=1x + y = 1x+y=1 doğrusu üzerinde kal.

fff'nin eş yükselti eğrileri orijin merkezli çemberler. Doğru üzerinde yürüdüğünü düşün. Bir çemberi kesiyorsan, doğru boyunca biraz daha ilerleyip daha küçük bir çembere geçebilirsin: henüz en iyi değilsin. En iyi nokta, doğrunun bir çembere teğet olduğu yerdir; orada daha küçük çembere geçemezsin.

Teğetlik anında iki eğrinin normalleri, yani gradyanları paraleldir:

∇f(x)=λ ∇g(x)\nabla f(x) = \lambda\, \nabla g(x)∇f(x)=λ∇g(x)

λ\lambdaλ (lambda) bir sayıdır: Lagrange çarpanı. İki gradyanın oranını söyler.

Lagrange fonksiyonu: kısıtlıyı kısıtsıza çevirmek

Bu koşulu tek bir fonksiyonda toplamak için Lagrange fonksiyonu kurulur:

L(x,λ)=f(x)−λ g(x)\mathcal{L}(x, \lambda) = f(x) - \lambda\, g(x)L(x,λ)=f(x)−λg(x)

L\mathcal{L}L'nin hem xxx'e hem λ\lambdaλ'ya göre gradyanını sıfırla:

  • ∇xL=0⇒∇f=λ∇g\nabla_x \mathcal{L} = 0 \Rightarrow \nabla f = \lambda \nabla g∇x​L=0⇒∇f=λ∇g (teğetlik)
  • ∂L/∂λ=0⇒g(x)=0\partial \mathcal{L}/\partial \lambda = 0 \Rightarrow g(x) = 0∂L/∂λ=0⇒g(x)=0 (kısıt sağlanıyor)

Elle çözüm: f=x2+y2f = x^2 + y^2f=x2+y2, g=x+y−1g = x + y - 1g=x+y−1.

  • ∇f=(2x,2y)\nabla f = (2x, 2y)∇f=(2x,2y), ∇g=(1,1)\nabla g = (1, 1)∇g=(1,1)
  • 2x=λ2x = \lambda2x=λ ve 2y=λ2y = \lambda2y=λ ⇒\Rightarrow⇒ x=yx = yx=y
  • Kısıt: x+y=1⇒x=y=0.5x + y = 1 \Rightarrow x = y = 0.5x+y=1⇒x=y=0.5; λ=2x=1\lambda = 2x = 1λ=2x=1; f=0.5f = 0.5f=0.5

λ\lambdaλ'nın anlamı: kısıtın "gölge fiyatı"

λ\lambdaλ, kısıtı biraz gevşetirsen en iyi değerin ne kadar değişeceğini söyler. Kısıt x+y=cx + y = cx+y=c olsun: en iyi değer f∗=c2/2f^* = c^2/2f∗=c2/2, türevi df∗/dc=cdf^*/dc = cdf∗/dc=c; c=1c=1c=1'de 1=λ1 = \lambda1=λ. Ekonomide "bütçeyi 1 TL artırsam kâr ne kadar artar?" sorusunun cevabı budur.

Kısıtlı optimizasyon: kurallara uyarak en iyiyi bulmak (devam)

Kısıt h(x)≥0h(x) \ge 0h(x)≥0 biçimindeyse iki durum var:

  • Kısıt aktif değil: Kısıtsız optimum zaten izin verilen bölgede. Kısıt hiç işe karışmaz, λ=0\lambda = 0λ=0.
  • Kısıt aktif: Optimum sınırın üstünde; eşitlik gibi davranır, λ>0\lambda > 0λ>0.

Bu "ya kısıt sıkıdır ya çarpan sıfırdır" kuralına tamamlayıcı gevşeklik denir (λ h(x)=0\lambda\, h(x) = 0λh(x)=0). Gradyan koşulu, kısıt, λ≥0\lambda \ge 0λ≥0 ve bu kural birlikte KKT koşullarıdır (Karush-Kuhn-Tucker).

Elle: x2+y2x^2+y^2x2+y2'yi x+y≥3x + y \ge 3x+y≥3 altında küçült: kısıtsız optimum (0,0)(0,0)(0,0) izinli değil, kısıt aktif, çözüm sınırda (1.5,1.5)(1.5, 1.5)(1.5,1.5). x+y≥−3x + y \ge -3x+y≥−3 altında ise (0,0)(0,0)(0,0) zaten izinli: kısıt pasif, λ=0\lambda=0λ=0.

ML'de nerede?

  • SVM (destek vektör makinesi): "Marjı en büyük yap, koşuluyla her nokta doğru tarafta kalsın." Her eğitim noktası bir eşitsizlik kısıtıdır, her birinin bir çarpanı (αi\alpha_iαi​) vardır. Tamamlayıcı gevşeklik gereği yalnız sınıra dayanan noktaların çarpanı sıfırdan büyüktür: bunlar destek vektörleridir. Diğer noktaları silsen model değişmez. Lagrange ile kurulan "dual" problem ayrıca kernel hilesini mümkün kılar.
  • Düzenlileştirme = kısıt: Ridge'in min⁡MSE+λ∥w∥2\min \text{MSE} + \lambda\|w\|^2minMSE+λ∥w∥2 formu, min⁡MSE\min \text{MSE}minMSE koşuluyla ∥w∥2≤t\|w\|^2 \le t∥w∥2≤t probleminin Lagrange biçimidir. Ceza katsayısının adının λ\lambdaλ olması tesadüf değil.
  • Maksimum entropi / softmax: "Olasılıklar toplamı 1" kısıtıyla entropiyi en büyük yapmak Lagrange ile çözülür; sonuç üstel (softmax biçimli) dağılımlardır.
  • KL-kısıtlı politika güncellemeleri: TRPO "politikayı iyileştir, koşuluyla eski politikadan KL uzaklığı ≤δ\le \delta≤δ". RLHF ve DPO'daki KL cezası bu kısıtın Lagrange (ceza) biçimidir.

# test: python 3.13 · numpy 2.5.4 · scipy 1.18.1
# PC'de çalıştır — gerekli: numpy, scipy, scikit-learn
import numpy as np
from scipy.optimize import minimize

# Problem: x^2 + y^2'yi en küçük yap, kısıt: x + y = 1
f = lambda v: v[0]**2 + v[1]**2
grad_f = lambda v: np.array([2 * v[0], 2 * v[1]])
g = lambda v: v[0] + v[1] - 1                   # kısıt g(v) = 0 biçiminde

# 1) Kütüphane: SciPy SLSQP kısıtı doğrudan alır
res = minimize(f, x0=[3.0, -1.0], method="SLSQP",
               constraints=[{"type": "eq", "fun": g}])
x, y = res.x
print(f"SLSQP: x={x:.4f}, y={y:.4f}, f={res.fun:.4f}")
# Lagrange koşulu: grad f = lambda * grad g. grad g = (1, 1) olduğundan lambda = 2x
print(f"grad f = {grad_f(res.x).round(4)}  -> lambda ≈ {2*x:.4f}")

# 2) Sıfırdan: ceza yöntemi. Kısıtı ihlal etmeyi pahalı yap, sonra düz GD.
#    F(v) = f(v) + c * g(v)^2 ;  c büyüdükçe çözüm kısıta yapışır
for c in [1, 10, 100, 1000]:
    v = np.array([3.0, -1.0])
    lr = 0.4 / (1 + 2 * c)                          # c büyüyünce yüzey dikleşir, adım küçülmeli
    for _ in range(50_000):
        v -= lr * (grad_f(v) + 2 * c * g(v) * np.array([1.0, 1.0]))
    print(f"c={c:5d}: x={v[0]:.4f}, y={v[1]:.4f}, kısıt ihlali g={g(v):+.5f}")

# 3) Eşitsizlik kısıtı: x + y >= 3 (sınır aktif) ve x + y >= -3 (aktif değil)
for b in [3, -3]:
    r = minimize(f, x0=[0.0, 0.0] if b > 0 else [2.0, 2.0], method="SLSQP",
                 constraints=[{"type": "ineq", "fun": lambda v, b=b: v[0] + v[1] - b}])
    print(f"x+y >= {b:+d}: çözüm {r.x.round(4)}")

# Çıktı:
# SLSQP: x=0.5000, y=0.5000, f=0.5000
# grad f = [1. 1.]  -> lambda ≈ 1.0000
# c=    1: x=0.3333, y=0.3333, kısıt ihlali g=-0.33333
# c=   10: x=0.4762, y=0.4762, kısıt ihlali g=-0.04762
# c=  100: x=0.4975, y=0.4975, kısıt ihlali g=-0.00498
# c= 1000: x=0.4998, y=0.4998, kısıt ihlali g=-0.00050
# x+y >= +3: çözüm [1.5 1.5]
# x+y >= -3: çözüm [0. 0.]

Okuma:

  • SLSQP elle bulduğumuz (0.5,0.5)(0.5, 0.5)(0.5,0.5), λ=1\lambda = 1λ=1 çözümünü veriyor; ∇f=(1,1)=1⋅∇g\nabla f = (1, 1) = 1 \cdot \nabla g∇f=(1,1)=1⋅∇g: gradyanlar paralel.
  • Ceza yöntemi (sıfırdan): kısıtı ihlal etmeyi c⋅g2c \cdot g^2c⋅g2 kadar pahalı yapıp düz GD uyguluyoruz. ccc büyüdükçe çözüm kısıta yaklaşıyor ama asla tam oturmuyor (ihlal tam olarak −1/(1+2c)-1/(1+2c)−1/(1+2c)). Dahası, ccc büyüdükçe yüzey bir yönde çok dikleşiyor: koşul sayısı patlıyor, öğrenme oranını küçültmek ve çok daha fazla adım atmak gerekiyor (U6-L1'deki vadi sorunu). Gerçek kısıtlı çözücüler bu yüzden Lagrange çarpanlarını doğrudan kullanır.
  • Eşitsizlikte x+y≥3x+y \ge 3x+y≥3 aktif (çözüm sınırda), x+y≥−3x+y \ge -3x+y≥−3 pasif (kısıtsız çözüm (0,0)(0,0)(0,0)).

from sklearn.svm import SVC
from sklearn.datasets import make_blobs

X, y = make_blobs(n_samples=200, centers=2, cluster_std=1.2, random_state=3)

print("karar değeri sklearn:", svm.decision_function(X[:3]).round(3))

Cevabı göster
