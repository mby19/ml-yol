Maksimum olabilirlik: veriyi en iyi açıklayan parametre

Problem

Elinde veri var; bir dağılım ailesi seçtin (Bernoulli, Gauss...), ama parametresini (ppp, μ\muμ, σ\sigmaσ, ağırlıklar...) bilmiyorsun. Hangi değeri seçmelisin? Bu derste ML'deki iki temel kaybın, log loss ve MSE'nin nereden geldiğini türeteceğiz. Bunlar keyfi seçimler değil; aynı ilkenin iki sonucu.

Olabilirlik: soru ters çevriliyor

Olasılık: "parametre p=0.5p = 0.5p=0.5 iken bu veriyi görme şansı nedir?" (parametre sabit, veri değişken).

Olabilirlik (likelihood): "bu veriyi gördüm; hangi parametre bunu ne kadar iyi açıklıyor?" (veri sabit, parametre değişken):

L(θ)=P(veri∣θ)\mathcal{L}(\theta) = P(\text{veri} \mid \theta)L(θ)=P(veri∣θ)

θ\thetaθ ("teta") parametre(ler) demek. Maksimum olabilirlik kestirimi (maximum likelihood estimation, MLE; gözlenen veriyi en olası kılan parametreyi seçme yöntemi):

θ^MLE=arg⁡max⁡θ  L(θ)\hat\theta_{\text{MLE}} = \arg\max_\theta \; \mathcal{L}(\theta)θ^MLE​=argθmax​L(θ)

arg⁡max⁡\arg\maxargmax: "fonksiyonu en büyük yapan girdi". Şapka (θ^\hat\thetaθ^), "veriden tahmin edilmiş" demek.

Elle: yazı-tura

L(p)=p7(1−p)3\mathcal{L}(p) = p^7 (1 - p)^3L(p)=p7(1−p)3

Log-olabilirlik: çarpımı toplama çevir

Çarpımla uğraşmak zor ve binlerce örnekte sayı sıfıra yuvarlanır. Logaritma artan bir fonksiyon olduğu için en büyüğün yerini değiştirmez, çarpımı toplama çevirir. Log-olabilirlik (log-likelihood; olabilirliğin logaritması, çarpımı toplama çevirir):

ℓ(p)=log⁡L(p)=7log⁡p+3log⁡(1−p)\ell(p) = \log\mathcal{L}(p) = 7\log p + 3\log(1 - p)ℓ(p)=logL(p)=7logp+3log(1−p)

En büyük noktada türev sıfırdır:

dℓdp=7p−31−p=0  ⇒  7(1−p)=3p  ⇒  p=0.7\frac{d\ell}{dp} = \frac{7}{p} - \frac{3}{1 - p} = 0 \;\Rightarrow\; 7(1 - p) = 3p \;\Rightarrow\; p = 0.7dpdℓ​=p7​−1−p3​=0⇒7(1−p)=3p⇒p=0.7

Genel olarak nnn atışta kkk tura için p^=k/n\hat p = k/np^​=k/n: sezginin söylediği "oran". MLE sezgiyi doğruladı; şimdi sezginin yetmediği yerlere uygulayalım.

Genel tarif

  1. Veri modeli seç: her örnek için p(xi∣θ)p(x_i \mid \theta)p(xi​∣θ).
  2. Örnekler bağımsız ve aynı dağılımdan (i.i.d.; independent and identically distributed, her örneğin aynı dağılımdan, diğerlerinden bağımsız gelmesi) varsayımıyla: L(θ)=∏ip(xi∣θ)\mathcal{L}(\theta) = \prod_i p(x_i \mid \theta)L(θ)=∏i​p(xi​∣θ).
  3. Log al: ℓ(θ)=∑ilog⁡p(xi∣θ)\ell(\theta) = \sum_i \log p(x_i \mid \theta)ℓ(θ)=∑i​logp(xi​∣θ).
  4. Ya türevi sıfıra eşitleyip çöz (kapalı form), ya da sayısal olarak optimize et.

ML'de en aza indirmeyi sevdiğimiz için genelde eksi işaretlisini kullanırız: negatif log-olabilirlik (NLL). "Olabilirliği en büyük yap" ile "NLL'yi en küçük yap" aynı şeydir. Ve örnek sayısına bölüp ortalama alınca, bu tam olarak bir kayıp fonksiyonudur.

Gauss için MLE

Veri x1,…,xn∼N(μ,σ2)x_1, \dots, x_n \sim \mathcal{N}(\mu, \sigma^2)x1​,…,xn​∼N(μ,σ2):

ℓ(μ,σ2)=−n2log⁡(2πσ2)−12σ2∑i(xi−μ)2\ell(\mu, \sigma^2) = -\frac{n}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum_i (x_i - \mu)^2ℓ(μ,σ2)=−2n​log(2πσ2)−2σ21​i∑​(xi​−μ)2

μ\muμ'ye göre türev sıfır: ∑i(xi−μ)=0⇒μ^=1n∑xi\sum_i(x_i - \mu) = 0 \Rightarrow \hat\mu = \frac{1}{n}\sum x_i∑i​(xi​−μ)=0⇒μ^​=n1​∑xi​, yani örnek ortalaması. σ2\sigma^2σ2'ye göre: σ^2=1n∑(xi−μ^)2\hat\sigma^2 = \frac{1}{n}\sum(x_i - \hat\mu)^2σ^2=n1​∑(xi​−μ^​)2. Dikkat: nnn'ye bölüyor, n−1n - 1n−1'e değil. MLE'nin varyans tahmini hafif yanlıdır (beklenti dersindeki ddof farkı buradan gelir).

MLE'den kayıp fonksiyonlarına: log loss ve MSE

Şimdi denetimli öğrenmeye geçiyoruz: girdi xi\mathbf{x}_ixi​, hedef yiy_iyi​, ağırlıklar w\mathbf{w}w. Model, yyy'nin dağılımının parametresini x\mathbf{x}x'ten tahmin eder. MLE: eğitim etiketlerini en olası kılan ağırlıkları seç.

1) Bernoulli → log loss (ikili çapraz entropi)

Hedef yi∈{0,1}y_i \in \{0, 1\}yi​∈{0,1}. Model her örnek için p^i=σ(w⊤xi)\hat p_i = \sigma(\mathbf{w}^\top\mathbf{x}_i)p^​i​=σ(w⊤xi​) verir ("yi=1y_i = 1yi​=1 olma olasılığı"). Varsayım: yi∼Bernoulli(p^i)y_i \sim \text{Bernoulli}(\hat p_i)yi​∼Bernoulli(p^​i​).

Tek örneğin olasılığı (dağılımlar dersindeki tek formül):

P(yi∣xi,w)=p^i yi(1−p^i)1−yiP(y_i \mid \mathbf{x}_i, \mathbf{w}) = \hat p_i^{\,y_i}(1 - \hat p_i)^{1 - y_i}P(yi​∣xi​,w)=p^​iyi​​(1−p^​i​)1−yi​

Bütün veri (i.i.d.): çarpım. Log al:

ℓ(w)=∑i[yilog⁡p^i+(1−yi)log⁡(1−p^i)]\ell(\mathbf{w}) = \sum_i \left[ y_i \log\hat p_i + (1 - y_i)\log(1 - \hat p_i) \right]ℓ(w)=i∑​[yi​logp^​i​+(1−yi​)log(1−p^​i​)]

Eksiyle çarp, nnn'ye böl:

NLL=−1n∑i[yilog⁡p^i+(1−yi)log⁡(1−p^i)]\boxed{\text{NLL} = -\frac{1}{n}\sum_i \left[ y_i \log\hat p_i + (1 - y_i)\log(1 - \hat p_i) \right]}NLL=−n1​i∑​[yi​logp^​i​+(1−yi​)log(1−p^​i​)]​

Bu tam olarak çapraz entropi (cross-entropy; log loss, doğru sınıfa verilen olasılığın negatif logaritmasının ortalaması) kaybıdır. scikit-learn'de log_loss, PyTorch'ta BCELoss / BCEWithLogitsLoss. Kimse bunu "uydurmadı"; Bernoulli varsayımının olabilirliğidir.

Elle: 3 örnek, y=(1,0,1)y = (1, 0, 1)y=(1,0,1), p^=(0.9,0.2,0.6)\hat p = (0.9, 0.2, 0.6)p^​=(0.9,0.2,0.6). Her örnekte "doğru cevaba verilen olasılık": 0.90.90.9, 1−0.2=0.81 - 0.2 = 0.81−0.2=0.8, 0.60.60.6.

NLL=−13(log⁡0.9+log⁡0.8+log⁡0.6)=−13(−0.1054−0.2231−0.5108)≈0.2798\text{NLL} = -\frac{1}{3}(\log 0.9 + \log 0.8 + \log 0.6) = -\frac{1}{3}(-0.1054 - 0.2231 - 0.5108) \approx 0.2798NLL=−31​(log0.9+log0.8+log0.6)=−31​(−0.1054−0.2231−0.5108)≈0.2798

Sezgi: Doğru cevaba 0.99 veren model neredeyse hiç ceza almaz (−log⁡0.99≈0.01-\log 0.99 \approx 0.01−log0.99≈0.01); 0.01 veren ağır ceza alır (−log⁡0.01≈4.6-\log 0.01 \approx 4.6−log0.01≈4.6). Kendinden emin yanlışlar en pahalısıdır.

Çok sınıf: Kategorik dağılım + softmax ile aynı yol −1n∑ilog⁡p^i,yi-\frac{1}{n}\sum_i \log \hat p_{i, y_i}−n1​∑i​logp^​i,yi​​ verir: doğru sınıfın olasılığının negatif logu. Dil modellerinin eğitim kaybı tam olarak budur.

Bonus: Bu kaybın w\mathbf{w}w'ye göre gradyanı şaşırtıcı derecede temizdir: 1nX⊤(p^−y)\frac{1}{n}X^\top(\hat{\mathbf{p}} - \mathbf{y})n1​X⊤(p^​−y). Taylor dersinde gradyan kontrolü yaptığımız fonksiyon buydu.

2) Gauss gürültü → MSE

Hedef gerçek sayı. Varsayım: gerçek değer = model tahmini + Gauss gürültü,

yi=f(xi;w)+εi,εi∼N(0,σ2)y_i = f(\mathbf{x}_i; \mathbf{w}) + \varepsilon_i, \qquad \varepsilon_i \sim \mathcal{N}(0, \sigma^2)yi​=f(xi​;w)+εi​,εi​∼N(0,σ2)

Yani yi∼N(f(xi;w),σ2)y_i \sim \mathcal{N}(f(\mathbf{x}_i; \mathbf{w}), \sigma^2)yi​∼N(f(xi​;w),σ2): ortalaması model tahmini olan bir çan. Tek örneğin yoğunluğu:

p(yi∣xi,w)=12πσ2exp⁡(−(yi−f(xi;w))22σ2)p(y_i \mid \mathbf{x}_i, \mathbf{w}) = \frac{1}{\sqrt{2\pi\sigma^2}}\exp\left(-\frac{(y_i - f(\mathbf{x}_i; \mathbf{w}))^2}{2\sigma^2}\right)p(yi​∣xi​,w)=2πσ2​1​exp(−2σ2(yi​−f(xi​;w))2​)

Log al ve topla:

ℓ(w)=−n2log⁡(2πσ2)⏟w’ye bag˘lı deg˘il−12σ2∑i(yi−f(xi;w))2\ell(\mathbf{w}) = \underbrace{-\frac{n}{2}\log(2\pi\sigma^2)}_{\mathbf{w}\text{'ye bağlı değil}} - \frac{1}{2\sigma^2}\sum_i \left(y_i - f(\mathbf{x}_i; \mathbf{w})\right)^2ℓ(w)=w’ye bag˘​lı deg˘​il−2n​log(2πσ2)​​−2σ21​i∑​(yi​−f(xi​;w))2

w\mathbf{w}w'ye göre en büyük yapmak için ilk terim önemsiz (sabit), 12σ2\frac{1}{2\sigma^2}2σ21​ de pozitif bir sabit çarpan. Geriye kalan:

w^MLE=arg⁡min⁡w  1n∑i(yi−f(xi;w))2=arg⁡min⁡w  MSE\hat{\mathbf{w}}_{\text{MLE}} = \arg\min_{\mathbf{w}} \; \frac{1}{n}\sum_i \left(y_i - f(\mathbf{x}_i; \mathbf{w})\right)^2 = \arg\min_{\mathbf{w}} \; \text{MSE}w^MLE​=argwmin​n1​i∑​(yi​−f(xi​;w))2=argwmin​MSE

MSE'yi en aza indirmek = Gauss gürültü varsayımı altında MLE. Doğrusal regresyonda bu "en küçük kareler" çözümünü verir. Gürültü varyansının MLE'si de σ^2=\hat\sigma^2 = σ^2= ortalama kare artık (eğitim MSE'si).

Bu türetmeler pratikte ne kazandırır?

  • Kayıp seçimi = varsayım seçimi. Hedefinde aykırı değerler varsa (kalın kuyruk) Gauss kötü bir varsayımdır; MSE aykırı değerlerin karesini aldığı için onlara aşırı tepki verir. Laplace gürültü varsayarsan aynı türetme MAE'yi (mutlak hata) verir; daha dayanıklıdır.
  • Sayım hedefi için Poisson NLL, olasılık hedefi için log loss: "hangi dağılım?" sorusu kaybı söyler.
  • Sınıflandırmada MSE yerine log loss kullanmanın nedeni de bu: hedef Bernoulli, Gauss değil.

MAP: önsel bilgiyle MLE = düzenlileştirme

MLE'nin zaafı: az veri

Yazı-turayı 3 kez attın, 3'ü de tura. MLE: p^=3/3=1\hat p = 3/3 = 1p^​=3/3=1. "Bu para asla yazı gelmez" demek saçma; az veriyle MLE aşırı emin olur. Aynısı modellerde aşırı öğrenme (overfitting; modelin eğitim verisini ezberleyip yeni veride kötüleşmesi) olarak görülür.

Bayes'i parametrelere uygula

Parametreyi de bir rastgele değişken gibi düşün ve önceden bir inanç (önsel) koy. Bayes teoremi:

p(θ∣veri)=p(veri∣θ) p(θ)p(veri)  ∝  p(veri∣θ)⏟olabilirlik  p(θ)⏟o¨nselp(\theta \mid \text{veri}) = \frac{p(\text{veri} \mid \theta)\,p(\theta)}{p(\text{veri})} \;\propto\; \underbrace{p(\text{veri} \mid \theta)}_{\text{olabilirlik}} \; \underbrace{p(\theta)}_{\text{önsel}}p(θ∣veri)=p(veri)p(veri∣θ)p(θ)​∝olabilirlikp(veri∣θ)​​o¨nselp(θ)​​

MAP kestirimi (maximum a posteriori; sonsal olasılığı en büyük yapan parametreyi seçme): paydanın θ\thetaθ'ya bağlı olmadığını kullanıp log al:

θ^MAP=arg⁡max⁡θ[log⁡p(veri∣θ)+log⁡p(θ)]\hat\theta_{\text{MAP}} = \arg\max_\theta \left[ \log p(\text{veri} \mid \theta) + \log p(\theta) \right]θ^MAP​=argθmax​[logp(veri∣θ)+logp(θ)]

MLE'ye tek fark: log⁡p(θ)\log p(\theta)logp(θ) terimi eklendi.

Elle: Beta önsel ile yazı-tura

"Paraların çoğu adildir" inancını Beta(aaa, bbb) önseliyle yazarız: p(θ)∝θa−1(1−θ)b−1p(\theta) \propto \theta^{a-1}(1 - \theta)^{b-1}p(θ)∝θa−1(1−θ)b−1. Beta(2, 2), 0.5 etrafında yumuşak bir tepe. nnn atışta kkk tura için log-sonsal:

(k+a−1)log⁡θ+(n−k+b−1)log⁡(1−θ)(k + a - 1)\log\theta + (n - k + b - 1)\log(1 - \theta)(k+a−1)logθ+(n−k+b−1)log(1−θ)

Bu, yazı-tura log-olabilirliğinin aynısı; sanki a−1a - 1a−1 ekstra tura ve b−1b - 1b−1 ekstra yazı görmüşüz gibi. Türev sıfır:

θ^MAP=k+a−1n+a+b−2\hat\theta_{\text{MAP}} = \frac{k + a - 1}{n + a + b - 2}θ^MAP​=n+a+b−2k+a−1​

3'te 3 tura, Beta(2, 2): θ^=3+13+2=0.8\hat\theta = \frac{3 + 1}{3 + 2} = 0.8θ^=3+23+1​=0.8. Daha makul. 300'de 300 olsaydı: 301/302≈0.997301/302 \approx 0.997301/302≈0.997. Veri arttıkça önselin etkisi kaybolur, MAP MLE'ye yaklaşır. Naive Bayes'teki Laplace düzeltmesi (her sayıma 1 eklemek) tam olarak böyle bir önseldir.

Gauss önsel → L2 düzenlileştirme (ridge)

Doğrusal regresyon, Gauss gürültü (σ2\sigma^2σ2) ve ağırlıklar üzerinde Gauss önsel: wj∼N(0,τ2)w_j \sim \mathcal{N}(0, \tau^2)wj​∼N(0,τ2), yani "ağırlıklar büyük olmamalı, sıfır civarında olmalı". Log önsel:

log⁡p(w)=−12τ2∑jwj2+sabit=−∥w∥22τ2+sabit\log p(\mathbf{w}) = -\frac{1}{2\tau^2}\sum_j w_j^2 + \text{sabit} = -\frac{\|\mathbf{w}\|^2}{2\tau^2} + \text{sabit}logp(w)=−2τ21​j∑​wj2​+sabit=−2τ2∥w∥2​+sabit

MAP, eksiyle çarpılınca en küçük yapılan şu ifade olur:

12σ2∑i(yi−w⊤xi)2+12τ2∥w∥2\frac{1}{2\sigma^2}\sum_i (y_i - \mathbf{w}^\top\mathbf{x}_i)^2 + \frac{1}{2\tau^2}\|\mathbf{w}\|^22σ21​i∑​(yi​−w⊤xi​)2+2τ21​∥w∥2

2σ22\sigma^22σ2 ile çarp (en küçüğün yeri değişmez):

∑i(yi−w⊤xi)2+λ∥w∥2,λ=σ2τ2\boxed{\sum_i (y_i - \mathbf{w}^\top\mathbf{x}_i)^2 + \lambda\|\mathbf{w}\|^2, \qquad \lambda = \frac{\sigma^2}{\tau^2}}i∑​(yi​−w⊤xi​)2+λ∥w∥2,λ=τ2σ2​​

MAP: önsel bilgiyle MLE = düzenlileştirme (devam)

Bu, ridge regresyonu (L2 düzenlileştirme; regularization, büyük ağırlıkları cezalandırarak aşırı öğrenmeyi azaltma). λ\lambdaλ'nın anlamı da çıktı: önsel dar (τ\tauτ küçük, "ağırlıklar sıfıra çok yakın olmalı") ya da gürültü büyükse (σ\sigmaσ büyük, "veriye az güven") λ\lambdaλ büyür. Derin öğrenmedeki "weight decay" aynı fikirdir.

Kapalı çözüm (lineer cebir ve matris türevleri dersinden): gradyanı sıfıra eşitle, −2X⊤(y−Xw)+2λw=0-2X^\top(\mathbf{y} - X\mathbf{w}) + 2\lambda\mathbf{w} = 0−2X⊤(y−Xw)+2λw=0:

w^MAP=(X⊤X+λI)−1X⊤y\hat{\mathbf{w}}_{\text{MAP}} = (X^\top X + \lambda I)^{-1}X^\top\mathbf{y}w^MAP​=(X⊤X+λI)−1X⊤y

Laplace önsel → L1 (lasso)

Önsel p(wj)∝exp⁡(−∣wj∣/b)p(w_j) \propto \exp(-|w_j|/b)p(wj​)∝exp(−∣wj​∣/b) (Laplace, sıfırda sivri tepe) seçilirse log önsel −1b∑∣wj∣-\frac{1}{b}\sum|w_j|−b1​∑∣wj​∣ olur: L1 cezası (lasso). Sivri tepe birçok ağırlığı tam sıfıra iter: otomatik özellik seçimi.

import numpy as np
from scipy.optimize import minimize_scalar
from sklearn.metrics import log_loss, mean_squared_error
from sklearn.linear_model import LinearRegression, Ridge

# 1) Yazı-tura MLE: ızgara, sayısal optimizasyon ve kapalı form
k, n = 7, 10
ps = np.linspace(0.001, 0.999, 999)
ll = k * np.log(ps) + (n - k) * np.log(1 - ps)
print(round(ps[ll.argmax()], 3))                                         # 0.7
res = minimize_scalar(lambda p: -(k*np.log(p) + (n-k)*np.log(1-p)), bounds=(1e-6, 1-1e-6), method="bounded")
print(round(res.x, 4), k / n)                                            # 0.7 0.7
print(f"{0.7**7 * 0.3**3:.6f}  {0.5**10:.6f}")                           # 0.002224  0.000977

# Neden log? 2000 atışlık olabilirlik çarpımı sıfıra yuvarlanır
x = (np.random.default_rng(0).random(2000) < 0.7).astype(float)
print(np.prod(np.where(x == 1, 0.7, 0.3)), round(np.sum(np.log(np.where(x == 1, 0.7, 0.3))), 1))   # 0.0 -1226.8

# 2) Bernoulli NLL = log loss
y = np.array([1, 0, 1]); p = np.array([0.9, 0.2, 0.6])
nll = -np.mean(y * np.log(p) + (1 - y) * np.log(1 - p))
print(round(nll, 4), round(log_loss(y, p), 4))                           # 0.2798 0.2798

# 3) Gauss gürültü: MLE = en küçük kareler = MSE minimumu
rng = np.random.default_rng(1)
X = rng.normal(size=(200, 2)); w_gercek = np.array([3.0, -2.0]); sigma = 0.5
yr = X @ w_gercek + rng.normal(0, sigma, size=200)

def gauss_nll(w, s2):                                                    # negatif log-olabilirlik
    r = yr - X @ w
    return 0.5 * len(yr) * np.log(2 * np.pi * s2) + (r @ r) / (2 * s2)

w_ls = np.linalg.lstsq(X, yr, rcond=None)[0]                            # en küçük kareler
w_sk = LinearRegression(fit_intercept=False).fit(X, yr).coef_
print(w_ls.round(3), np.allclose(w_ls, w_sk))                            # [ 3.01  -1.995] True
# Ağırlığı biraz bozunca hem MSE hem NLL artar (her sigma için)
for s2 in (0.1, 1.0):
    print(gauss_nll(w_ls, s2) < gauss_nll(w_ls + [0.05, 0], s2))         # True  True
s2_mle = mean_squared_error(yr, X @ w_ls)                                # sigma^2'nin MLE'si = eğitim MSE'si
print(round(s2_mle, 3), sigma**2)                                        # 0.259 0.25

# 4) MAP: Beta(2,2) önsel ile 3/3 tura
for k_, n_ in [(3, 3), (300, 300)]:
    print(k_ / n_, round((k_ + 1) / (n_ + 2), 3))                        # 1.0 0.8   /   1.0 0.997

# 5) Gauss önsel = ridge: kapalı form vs scikit-learn
Xs = rng.normal(size=(15, 5)); ys = Xs @ np.array([1., 0., -1., 0., 2.]) + rng.normal(0, 1.0, 15)
lam = 3.0
w_map = np.linalg.solve(Xs.T @ Xs + lam * np.eye(5), Xs.T @ ys)
w_ridge = Ridge(alpha=lam, fit_intercept=False).fit(Xs, ys).coef_
print(np.allclose(w_map, w_ridge))                                       # True
w_mle = np.linalg.lstsq(Xs, ys, rcond=None)[0]
print(round(np.linalg.norm(w_mle), 3), round(np.linalg.norm(w_map), 3))  # 2.978 2.225  (MAP ağırlıkları daha küçük)
