Distributions

Now that we have learned how to work with probability in both the discrete and the continuous setting, let's get to know some of the common distributions encountered. Depending on the area of machine learning, we may need to be familiar with vastly more of these, or for some areas of deep learning potentially none at all. This is, however, a good basic list to be familiar with. Let's first import some common libraries.

Binomial

Let's make things a little more complex and examine the binomial random variable. This random variable originates from performing a sequence of nnn independent experiments, each of which has probability ppp of succeeding, and asking how many successes we expect to see.

Let's express this mathematically. Each experiment is an independent random variable XiX_iXi​ where we will use 111 to encode success, and 000 to encode failure. Since each is an independent coin flip which is successful with probability ppp, we can say that Xi∼Bernoulli(p)X_i \sim \textrm{Bernoulli}(p)Xi​∼Bernoulli(p). Then, the binomial random variable is

X=∑i=1nXi.X = \sum_{i=1}^n X_i.X=i=1∑n​Xi​.

In this case, we will write

X∼Binomial(n,p).X \sim \textrm{Binomial}(n, p).X∼Binomial(n,p).

To get the cumulative distribution function, we need to notice that getting exactly kkk successes can occur in (nk)=n!k!(n−k)!\binom{n}{k} = \frac{n!}{k!(n-k)!}(kn​)=k!(n−k)!n!​ ways each of which has a probability of pk(1−p)n−kp^k(1-p)^{n-k}pk(1−p)n−k of occurring. Thus the cumulative distribution function is

F(x)={0x<0,∑m≤k(nm)pm(1−p)n−mk≤x<k+1 with 0≤k<n,1x>=n.F(x) = \begin{cases} 0 & x < 0, \\ \sum_{m \le k} \binom{n}{m} p^m(1-p)^{n-m} & k \le x < k+1 \textrm{ with } 0 \le k < n, \\ 1 & x >= n . \end{cases}F(x)=⎩⎨⎧​0∑m≤k​(mn​)pm(1−p)n−m1​x<0,k≤x<k+1 with 0≤k<n,x>=n.​ Let's first plot the probability mass function.

n, p = 10, 0.2

# Compute binomial coefficient
def binom(n, k):
    comb = 1
    for i in range(min(k, n - k)):
        comb = comb * (n - i) // (i + 1)
    return comb

d2l.plt.stem([i for i in range(n + 1)], pmf, use_line_collection=True)
d2l.plt.xlabel('x')
d2l.plt.ylabel('p.m.f.')
d2l.plt.show()

Now, let's plot the cumulative distribution function (see equation above).

x = torch.arange(-1, 11, 0.01)

def F(x):
    return 0 if x < 0 else 1 if x > n else cmf[int(x)]

If X∼Binomial(n,p)X \sim \textrm{Binomial}(n, p)X∼Binomial(n,p), then:

  • μX=np\mu_X = npμX​=np,
  • σX2=np(1−p)\sigma_X^2 = np(1-p)σX2​=np(1−p).

This follows from the linearity of expected value over the sum of nnn Bernoulli random variables, and the fact that the variance of the sum of independent random variables is the sum of the variances. This can be sampled as follows.

Poisson

Let's now perform a thought experiment. We are standing at a bus stop and we want to know how many buses will arrive in the next minute. Let's start by considering X(1)∼Bernoulli(p)X^{(1)} \sim \textrm{Bernoulli}(p)X(1)∼Bernoulli(p) which is simply the probability that a bus arrives in the one minute window. For bus stops far from an urban center, this might be a pretty good approximation. We may never see more than one bus in a minute.

However, if we are in a busy area, it is possible or even likely that two buses will arrive. We can model this by splitting our random variable into two parts for the first 30 seconds, or the second 30 seconds. In this case we can write

X(2)∼X1(2)+X2(2),X^{(2)} \sim X^{(2)}_1 + X^{(2)}_2,X(2)∼X1(2)​+X2(2)​,

where X(2)X^{(2)}X(2) is the total sum, and Xi(2)∼Bernoulli(p/2)X^{(2)}_i \sim \textrm{Bernoulli}(p/2)Xi(2)​∼Bernoulli(p/2). The total distribution is then X(2)∼Binomial(2,p/2)X^{(2)} \sim \textrm{Binomial}(2, p/2)X(2)∼Binomial(2,p/2).

Why stop here? Let's continue to split that minute into nnn parts. By the same reasoning as above, we see that

X(n)∼Binomial(n,p/n).X^{(n)} \sim \textrm{Binomial}(n, p/n).X(n)∼Binomial(n,p/n). Consider these random variables. By the previous section, we know that (see equation above) has mean μX(n)=n(p/n)=p\mu_{X^{(n)}} = n(p/n) = pμX(n)​=n(p/n)=p, and variance σX(n)2=n(p/n)(1−(p/n))=p(1−p/n)\sigma_{X^{(n)}}^2 = n(p/n)(1-(p/n)) = p(1-p/n)σX(n)2​=n(p/n)(1−(p/n))=p(1−p/n). If we take n→∞n \rightarrow \inftyn→∞, we can see that these numbers stabilize to μX(∞)=p\mu_{X^{(\infty)}} = pμX(∞)​=p, and variance σX(∞)2=p\sigma_{X^{(\infty)}}^2 = pσX(∞)2​=p. This indicates that there could be some random variable we can define in this infinite subdivision limit.

This should not come as too much of a surprise, since in the real world we can just count the number of bus arrivals, however it is nice to see that our mathematical model is well defined. This discussion can be made formal as the law of rare events.

Following through this reasoning carefully, we can arrive at the following model. We will say that X∼Poisson(λ)X \sim \textrm{Poisson}(\lambda)X∼Poisson(λ) if it is a random variable which takes the values {0,1,2,…}\{0,1,2, \ldots\}{0,1,2,…} with probability

pk=λke−λk!.p_k = \frac{\lambda^ke^{-\lambda}}{k!}.pk​=k!λke−λ​. The value λ>0\lambda > 0λ>0 is known as the rate (or the shape parameter), and denotes the average number of arrivals we expect in one unit of time.

We may sum this probability mass function to get the cumulative distribution function.

F(x)={0x<0,e−λ∑m=0kλmm!k≤x<k+1 with 0≤k.F(x) = \begin{cases} 0 & x < 0, \\ e^{-\lambda}\sum_{m = 0}^k \frac{\lambda^m}{m!} & k \le x < k+1 \textrm{ with } 0 \le k. \end{cases}F(x)={0e−λ∑m=0k​m!λm​​x<0,k≤x<k+1 with 0≤k.​ Let's first plot the probability mass function (see equation above).

Gaussian

Now Let's try a different, but related experiment. Let's say we again are performing nnn independent Bernoulli(p)\textrm{Bernoulli}(p)Bernoulli(p) measurements XiX_iXi​. The distribution of the sum of these is X(n)∼Binomial(n,p)X^{(n)} \sim \textrm{Binomial}(n, p)X(n)∼Binomial(n,p). Rather than taking a limit as nnn increases and ppp decreases, Let's fix ppp, and then send n→∞n \rightarrow \inftyn→∞. In this case μX(n)=np→∞\mu_{X^{(n)}} = np \rightarrow \inftyμX(n)​=np→∞ and σX(n)2=np(1−p)→∞\sigma_{X^{(n)}}^2 = np(1-p) \rightarrow \inftyσX(n)2​=np(1−p)→∞, so there is no reason to think this limit should be well defined.

However, not all hope is lost! Let's just make the mean and variance be well behaved by defining

Y(n)=X(n)−μX(n)σX(n).Y^{(n)} = \frac{X^{(n)} - \mu_{X^{(n)}}}{\sigma_{X^{(n)}}}.Y(n)=σX(n)​X(n)−μX(n)​​.

This can be seen to have mean zero and variance one, and so it is plausible to believe that it will converge to some limiting distribution. If we plot what these distributions look like, we will become even more convinced that it will work.

p = 0.2
ns = [1, 10, 100, 1000]
d2l.plt.figure(figsize=(10, 3))
for i in range(4):
    n = ns[i]
    pmf = torch.tensor([p**i * (1-p)**(n-i) * binom(n, i)
                        for i in range(n + 1)])
    d2l.plt.subplot(1, 4, i + 1)
    d2l.plt.stem([(i - n*p)/torch.sqrt(torch.tensor(n*p*(1 - p)))
                  for i in range(n + 1)], pmf,
                 use_line_collection=True)
    d2l.plt.xlim([-4, 4])
    d2l.plt.xlabel('x')
    d2l.plt.ylabel('p.m.f.')
    d2l.plt.title("n = {}".format(n))
d2l.plt.show()

One thing to note: compared to the Poisson case, we are now dividing by the standard deviation which means that we are squeezing the possible outcomes into smaller and smaller areas. This is an indication that our limit will no longer be discrete, but rather continuous.

A derivation of what occurs is beyond the scope of this document, but the central limit theorem states that as n→∞n \rightarrow \inftyn→∞, this will yield the Gaussian Distribution (or sometimes normal distribution). More explicitly, for any a,ba, ba,b:

lim⁡n→∞P(Y(n)∈[a,b])=P(N(0,1)∈[a,b]),\lim_{n \rightarrow \infty} P(Y^{(n)} \in [a, b]) = P(\mathcal{N}(0,1) \in [a, b]),n→∞lim​P(Y(n)∈[a,b])=P(N(0,1)∈[a,b]),

where we say a random variable is normally distributed with given mean μ\muμ and variance σ2\sigma^2σ2, written X∼N(μ,σ2)X \sim \mathcal{N}(\mu, \sigma^2)X∼N(μ,σ2) if XXX has density

pX(x)=12πσ2e−(x−μ)22σ2.p_X(x) = \frac{1}{\sqrt{2\pi\sigma^2}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}.pX​(x)=2πσ2​1​e−2σ2(x−μ)2​. Let's first plot the probability density function (see equation above).

mu, sigma = 0, 1

x = torch.arange(-3, 3, 0.01)
p = 1 / torch.sqrt(2 * torch.pi * sigma**2) * torch.exp(
    -(x - mu)**2 / (2 * sigma**2))

d2l.plot(x, p, 'x', 'p.d.f.')

Now, let's plot the cumulative distribution function. It is beyond the scope of this appendix, but the Gaussian c.d.f. does not have a closed-form formula in terms of more elementary functions. We will use erf which provides a way to compute this integral numerically.

def phi(x):
    return (1.0 + erf((x - mu) / (sigma * torch.sqrt(d2l.tensor(2.))))) / 2.0

d2l.plot(x, torch.tensor([phi(y) for y in x.tolist()]), 'x', 'c.d.f.')

Keen-eyed readers will recognize some of these terms. Indeed, we encountered this integral in (see related section). Indeed we need exactly that computation to see that this pX(x)p_X(x)pX​(x) has total area one and is thus a valid density.

Our choice of working with coin flips made computations shorter, but nothing about that choice was fundamental. Indeed, if we take any collection of independent identically distributed random variables XiX_iXi​, and form

X(N)=∑i=1NXi.X^{(N)} = \sum_{i=1}^N X_i.X(N)=i=1∑N​Xi​.

Then

X(N)−μX(N)σX(N)\frac{X^{(N)} - \mu_{X^{(N)}}}{\sigma_{X^{(N)}}}σX(N)​X(N)−μX(N)​​

will be approximately Gaussian. There are additional requirements needed to make it work, most commonly E[X4]<∞E[X^4] < \inftyE[X4]<∞, but the philosophy is clear.

The central limit theorem is the reason why the Gaussian is fundamental to probability, statistics, and machine learning. Whenever we can say that something we measured is a sum of many small independent contributions, we can assume that the thing being measured will be close to Gaussian.

There are many more fascinating properties of Gaussians, and we would like to discuss one more here. The Gaussian is what is known as a maximum entropy distribution. We will get into entropy more deeply in (see related section), however all we need to know at this point is that it is a measure of randomness. In a rigorous mathematical sense, we can think of the Gaussian as the most random choice of random variable with fixed mean and variance. Thus, if we know that our random variable has some mean and variance, the Gaussian is in a sense the most conservative choice of distribution we can make.

To close the section, let's recall that if X∼N(μ,σ2)X \sim \mathcal{N}(\mu, \sigma^2)X∼N(μ,σ2), then:

  • μX=μ\mu_X = \muμX​=μ,
  • σX2=σ2\sigma_X^2 = \sigma^2σX2​=σ2.

We can sample from the Gaussian (or standard normal) distribution as shown below.

Exponential Family

One shared property for all the distributions listed above is that they all belong to which is known as the exponential family. The exponential family is a set of distributions whose density can be expressed in the following form:

p(x∣η)=h(x)⋅exp⁡(η⊤⋅T(x)−A(η))p(\mathbf{x} \mid \boldsymbol{\eta}) = h(\mathbf{x}) \cdot \exp \left( \boldsymbol{\eta}^{\top} \cdot T(\mathbf{x}) - A(\boldsymbol{\eta}) \right)p(x∣η)=h(x)⋅exp(η⊤⋅T(x)−A(η)) As this definition can be a little subtle, let's examine it closely.

First, h(x)h(\mathbf{x})h(x) is known as the underlying measure or the base measure. This can be viewed as an original choice of measure we are modifying with our exponential weight.

Second, we have the vector η=(η1,η2,...,ηl)∈Rl\boldsymbol{\eta} = (\eta_1, \eta_2, ..., \eta_l) \in \mathbb{R}^lη=(η1​,η2​,...,ηl​)∈Rl called the natural parameters or canonical parameters. These define how the base measure will be modified. The natural parameters enter into the new measure by taking the dot product of these parameters against some function T(⋅)T(\cdot)T(⋅) of x=(x1,x2,...,xn)∈Rn\mathbf{x}= (x_1, x_2, ..., x_n) \in \mathbb{R}^nx=(x1​,x2​,...,xn​)∈Rn and exponentiated. The vector T(x)=(T1(x),T2(x),...,Tl(x))T(\mathbf{x})= (T_1(\mathbf{x}), T_2(\mathbf{x}), ..., T_l(\mathbf{x}))T(x)=(T1​(x),T2​(x),...,Tl​(x)) is called the sufficient statistics for η\boldsymbol{\eta}η. This name is used since the information represented by T(x)T(\mathbf{x})T(x) is sufficient to calculate the probability density and no other information from the sample x\mathbf{x}x's are required.

Third, we have A(η)A(\boldsymbol{\eta})A(η), which is referred to as the cumulant function, which ensures that the above distribution (see equation above) integrates to one, i.e.,

\left(\boldsymbol{\eta}^{\top} \cdot T(\mathbf{x}) \right) d\mathbf{x} \right].$$ To be concrete, let's consider the Gaussian. Assuming that $\mathbf{x}$ is an univariate variable, we saw that it had a density of

\begin{aligned} p(x \mid \mu, \sigma) &= \frac{1}{\sqrt{2 \pi \sigma^2}} \cdot \exp \left{ \frac{-(x-\mu)^2}{2 \sigma^2} \right} \ &= \frac{1}{\sqrt{2 \pi}} \cdot \exp \left{ \frac{\mu}{\sigma^2}x -\frac{1}{2 \sigma^2} x^2 - \left( \frac{1}{2 \sigma^2} \mu^2 +\log(\sigma) \right) \right}. \end{aligned}

This matches the definition of the exponential family with: * *underlying measure*: $h(x) = \frac{1}{\sqrt{2 \pi}}$, * *natural parameters*: $\boldsymbol{\eta} = \begin{bmatrix} \eta_1 \\ \eta_2 \end{bmatrix} = \begin{bmatrix} \frac{\mu}{\sigma^2} \\ \frac{1}{2 \sigma^2} \end{bmatrix}$, * *sufficient statistics*: $T(x) = \begin{bmatrix}x\\-x^2\end{bmatrix}$, and * *cumulant function*: $A({\boldsymbol\eta}) = \frac{1}{2 \sigma^2} \mu^2 + \log(\sigma) = \frac{\eta_1^2}{4 \eta_2} - \frac{1}{2}\log(2 \eta_2)$. It is worth noting that the exact choice of each of above terms is somewhat arbitrary. Indeed, the important feature is that the distribution can be expressed in this form, not the exact form itself. As we allude to in (see related section), a widely used technique is to assume that the final output $\mathbf{y}$ follows an exponential family distribution. The exponential family is a common and powerful family of distributions encountered frequently in machine learning.

Summary

  • Bernoulli random variables can be used to model events with a yes/no outcome.
  • Discrete uniform distributions model selects from a finite set of possibilities.
  • Continuous uniform distributions select from an interval.
  • Binomial distributions model a series of Bernoulli random variables, and count the number of successes.
  • Poisson random variables model the arrival of rare events.
  • Gaussian random variables model the result of adding a large number of independent random variables together.
  • All the above distributions belong to exponential family.
