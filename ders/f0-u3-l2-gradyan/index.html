Kısmi türev: diğer düğmeler sabitken bir düğme

Gerçek bir modelde tek düğme yoktur; milyonlarca vardır. Kayıp L(w1,w2,…,wn)L(w_1, w_2, \dots, w_n)L(w1​,w2​,…,wn​) çok değişkenli bir fonksiyondur. Soru aynı kalır: bu düğmeyi biraz çevirirsem kayıp ne kadar değişir? Ama artık "diğer düğmelere dokunmadan" demeliyiz.

Tanım

Kısmi türev (partial derivative; diğer bütün değişkenler sabit tutulurken tek bir değişkene göre alınan türev):

∂f∂x(x,y)=lim⁡h→0f(x+h,y)−f(x,y)h\frac{\partial f}{\partial x}(x, y) = \lim_{h \to 0} \frac{f(x + h, y) - f(x, y)}{h}∂x∂f​(x,y)=h→0lim​hf(x+h,y)−f(x,y)​

∂\partial∂ ("kısmi" ya da "del" diye okunur) normal ddd'den farkını gösterir: yalnız xxx hareket ediyor, yyy donmuş.

Nasıl hesaplanır: Diğer değişkenleri sabit sayı gibi düşün, normal türev al.

Elle örnek

f(x,y)=x2+3xy+y2f(x, y) = x^2 + 3xy + y^2f(x,y)=x2+3xy+y2
  • xxx'e göre (yyy sabit): x2x^2x2'nin türevi 2x2x2x; 3xy3xy3xy'de 3y3y3y bir sabit katsayı, türevi 3y3y3y; y2y^2y2 sabit, türevi 0. Sonuç: ∂f∂x=2x+3y\frac{\partial f}{\partial x} = 2x + 3y∂x∂f​=2x+3y.
  • yyy'ye göre (xxx sabit): ∂f∂y=3x+2y\frac{\partial f}{\partial y} = 3x + 2y∂y∂f​=3x+2y.

(x,y)=(1,2)(x, y) = (1, 2)(x,y)=(1,2) noktasında: ∂f∂x=2+6=8\frac{\partial f}{\partial x} = 2 + 6 = 8∂x∂f​=2+6=8, ∂f∂y=3+4=7\frac{\partial f}{\partial y} = 3 + 4 = 7∂y∂f​=3+4=7.

Gradyan: bütün kısmi türevleri bir vektörde topla

Gradyan (gradient; bir fonksiyonun bütün kısmi türevlerini sıralayan vektör) ∇f\nabla f∇f ile gösterilir (∇\nabla∇ "nabla"):

∇f(x,y)=[∂f∂x∂f∂y]=[2x+3y3x+2y],∇f(1,2)=[87]\nabla f(x, y) = \begin{bmatrix} \frac{\partial f}{\partial x} \\ \frac{\partial f}{\partial y} \end{bmatrix} = \begin{bmatrix} 2x + 3y \\ 3x + 2y \end{bmatrix}, \quad \nabla f(1, 2) = \begin{bmatrix} 8 \\ 7 \end{bmatrix}∇f(x,y)=[∂x∂f​∂y∂f​​]=[2x+3y3x+2y​],∇f(1,2)=[87​]

Gradyanın yönü: en dik yokuş

Dağ benzetmesi

Sisli bir dağdasın, yalnız ayağının altındaki eğimi hissedebiliyorsun. Gradyan, en dik yukarı çıkan yönü gösteren bir oktur; okun uzunluğu o yöndeki dikliktir. Ters ok (−∇f-\nabla f−∇f) en dik aşağı inen yöndür.

Neden en dik yön gradyan?

Birim uzunlukta bir yön u\mathbf{u}u seç (uzunluğu 1 olan bir ok). O yönde küçük bir adım atınca fff'nin değişim hızına yönlü türev (directional derivative; fonksiyonun belli bir yöndeki değişim hızı) denir:

Duf=∇f⋅u=∥∇f∥ ∥u∥cos⁡θ=∥∇f∥cos⁡θD_{\mathbf{u}} f = \nabla f \cdot \mathbf{u} = \|\nabla f\| \, \|\mathbf{u}\| \cos\theta = \|\nabla f\| \cos\thetaDu​f=∇f⋅u=∥∇f∥∥u∥cosθ=∥∇f∥cosθ

θ\thetaθ, u\mathbf{u}u ile gradyan arasındaki açıdır; ∥⋅∥\|\cdot\|∥⋅∥ uzunluk demek. cos⁡θ\cos\thetacosθ en büyük değerini (1) açı 0 iken alır, yani u\mathbf{u}u gradyanla aynı yöndeyken. En küçük değerini (−1) tam ters yönde alır. Gradyana dik yönde (θ=90°\theta = 90°θ=90°) cos⁡θ=0\cos\theta = 0cosθ=0: o yönde fonksiyon ilk anda değişmez (eş yükselti çizgisi boyunca yürüyorsun).

ML bağlantısı: gradyan = öğrenme yönü

Kayıp L(w)L(\mathbf{w})L(w) için ∇L\nabla L∇L, "kaybı en hızlı artıran" parametre değişimini gösterir. Öğrenmek, bu okun tersine küçük bir adım atmaktır. Gradyanın her elemanı ayrıca bir teşhis aracıdır:

  • Bir ağırlığın kısmi türevi büyükse, o ağırlık şu an kaybı çok etkiliyor.
  • Sıfıra yakınsa, o düğme şu an işe yaramıyor (ya iyi ayarlanmış ya da "ölü": ör. hep negatif girdi alan ReLU).

Tuzaklar

  • Ölçek farkı: Bir özellik 0-1, diğeri 0-100000 aralığındaysa kısmi türevler de binlerce kat farklı olur; gradyan yönü neredeyse tamamen büyük özelliğe bakar. Bu yüzden özellikler ölçeklenir (standardizasyon).

Sıfırdan sayısal gradyan, yönlü türev deneyi ve MSE gradyanının kontrolü:

# test: python 3.13 · numpy 2.5.4
# PC'de çalıştır: pip install numpy
import numpy as np

def f(p):
    x, y = p
    return x**2 + 3*x*y + y**2

def analitik_grad(p):
    x, y = p
    return np.array([2*x + 3*y, 3*x + 2*y])

def sayisal_grad(f, p, h=1e-5):
    p = np.asarray(p, dtype=float)
    g = np.zeros_like(p)
    for i in range(len(p)):          # her düğmeyi tek tek oynat, diğerleri sabit
        e = np.zeros_like(p); e[i] = h
        g[i] = (f(p + e) - f(p - e)) / (2 * h)
    return g

p = np.array([1.0, 2.0])
print(analitik_grad(p))              # [8. 7.]
print(sayisal_grad(f, p).round(6))   # [8. 7.]

# Yönlü türev: 360 farklı birim yön dene, hangisinde f en hızlı artıyor?
g = analitik_grad(p)
acilar = np.deg2rad(np.arange(360))
yonler = np.stack([np.cos(acilar), np.sin(acilar)], axis=1)   # (360, 2) birim vektörler
hizlar = yonler @ g                                            # her yön için ∇f·u
en_iyi = yonler[hizlar.argmax()]
print("en hızlı yön :", en_iyi.round(3))                     # en hızlı yön : [0.755 0.656]
print("gradyan yönü :", (g / np.linalg.norm(g)).round(3))    # gradyan yönü : [0.753 0.659]
print("en büyük hız :", hizlar.max().round(3), " |∇f| =", np.linalg.norm(g).round(3))  # en büyük hız : 10.63  |∇f| = 10.63

# Doğrusal regresyon MSE gradyanı
x = np.array([1.0, 2.0, 3.0]); y = np.array([2.0, 4.0, 6.0])
def mse(params):
    w, b = params
    return np.mean((w * x + b - y)**2)
def mse_grad(params):
    w, b = params
    hata = w * x + b - y
    return np.array([2 * np.mean(hata * x), 2 * np.mean(hata)])
print(mse_grad([1.0, 0.0]).round(4))                 # [-9.3333 -4.    ]
print(sayisal_grad(mse, [1.0, 0.0]).round(4))       # [-9.3333 -4.    ]

Kütüphaneyle: SciPy'nin check_grad fonksiyonu analitik ve sayısal gradyan arasındaki farkın uzunluğunu verir.

# test: python 3.13 · numpy 2.5.4 · scipy 1.18.1
# PC'de çalıştır: pip install numpy scipy
import numpy as np
from scipy.optimize import approx_fprime, check_grad

f = lambda p: p[0]**2 + 3*p[0]*p[1] + p[1]**2
grad = lambda p: np.array([2*p[0] + 3*p[1], 3*p[0] + 2*p[1]])
p = np.array([1.0, 2.0])
print(approx_fprime(p, f, 1e-6).round(4))   # [8. 7.]
print(check_grad(f, grad, p) < 1e-4)        # True  (fark çok küçük: analitik gradyan doğru)

# Yanlış gradyan yazsaydık (y terimini unutalım):
yanlis = lambda p: np.array([2*p[0], 3*p[0] + 2*p[1]])
print(round(check_grad(f, yanlis, p), 2))   # 6.0   (büyük fark: hata var)

Özet11 / 11
  • Kısmi türev: diğer değişkenler sabitken tek değişkene göre türev; diğerlerini sayı gibi düşün.
  • Gradyan ∇f\nabla f∇f: bütün kısmi türevlerin vektörü; modelde parametre sayısı kadar uzun.
  • Δf≈∇f⋅Δ\Delta f \approx \nabla f \cdot \DeltaΔf≈∇f⋅Δ: küçük toplu değişimin doğrusal tahmini.
  • Yönlü türev ∇f⋅u=∥∇f∥cos⁡θ\nabla f \cdot \mathbf{u} = \|\nabla f\|\cos\theta∇f⋅u=∥∇f∥cosθ; en büyük değer gradyan yönünde, en küçük ters yönde, sıfır dik yönde.
  • ML: −∇L-\nabla L−∇L kaybı en hızlı azaltan yöndür (algoritma U6'da). Gradyan elemanları hangi parametrenin önemli olduğunu gösterir.
  • MSE gradyanı: ∂L∂w=2n∑(y^i−yi)xi\frac{\partial L}{\partial w} = \frac{2}{n}\sum(\hat y_i - y_i)x_i∂w∂L​=n2​∑(y^​i​−yi​)xi​.
