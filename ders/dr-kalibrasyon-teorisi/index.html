Doğru skor kuralı (proper scoring rule) nedir?

Ana derste kalibrasyonu grafikle ve Brier skoruyla gördünüz. Bu ders, "hangi metrik modeli dürüst olmaya zorlar?" sorusunu cevaplıyor. Cevap tek kelime: proper olması.

Tanım: proper skor kuralı

Bir skor kuralı S(p,y)S(p,y)S(p,y) olsun; ppp modelin olasılık tahmini, y∈{0,1}y\in\{0,1\}y∈{0,1} gözlem. Yüksek iyi. Kural, gerçek olasılık qqq iken beklenen skoru qqq'da maksimize ediyorsa proper; bunu yalnız p=qp=qp=q'da yapıyorsa strictly proper:

Ey∼q[S(q,y)]  ≥  Ey∼q[S(p,y)]∀p,q\mathbb{E}_{y\sim q}\big[S(q,y)\big] \;\ge\; \mathbb{E}_{y\sim q}\big[S(p,y)\big]\quad \forall p, qEy∼q​[S(q,y)]≥Ey∼q​[S(p,y)]∀p,q

Bu tanım tam olarak şunu söylüyor: doğruyu söylemek (kendi inancını bildirmek) en kârlı stratejidir. Model, gerçek frekansı bilip bilmediğinden bağımsız olarak, bildiği olasılığı yazmaya teşvik edilir. Skor kuralı bu özelliğe sahip değilse, kalibrasyon ölçümü anlamsızlaşır: model "kendini iyi gösterecek" biçimde rapor verir.

Brier skoru: türetme

SB(p,y)=−(p−y)2⇒Ey∼q[SB]=−[q(1−p)2+(1−q)p2]S_B(p,y) = -(p-y)^2 \quad\Rightarrow\quad \mathbb{E}_{y\sim q}[S_B] = -\big[q(1-p)^2+(1-q)p^2\big]SB​(p,y)=−(p−y)2⇒Ey∼q​[SB​]=−[q(1−p)2+(1−q)p2]

Parantezi açalım: q(1−2p+p2)+p2−qp2=q−2qp+p2q(1-2p+p^2)+p^2-qp^2 = q-2qp+p^2q(1−2p+p2)+p2−qp2=q−2qp+p2. Yani

E[SB]=−(p−q)2−q(1−q)\mathbb{E}[S_B] = -(p-q)^2 - q(1-q)E[SB​]=−(p−q)2−q(1−q)

İspat bitti: ilk terim p=qp=qp=q'da sıfır, her yerde negatif. Ceza tam olarak (p−q)2(p-q)^2(p−q)2, yani kalibrasyondan sapmanın karesi. Ayrıca q(1−q)q(1-q)q(1−q) terimi modelden bağımsız: hiçbir tahmin o tabanı aşamaz.

Sayısal: q=0.7q=0.7q=0.7. Model p=0.5p=0.5p=0.5 derse beklenen Brier −(0.2)2−0.21=−0.25-(0.2)^2-0.21 = -0.25−(0.2)2−0.21=−0.25; p=0.7p=0.7p=0.7 derse −0.21-0.21−0.21. Fark 0.040.040.04 — sapmanın karesi. Brier bir strictly proper kuraldır.

Log kaybı: türetme

SL(p,y)=−[ylog⁡p+(1−y)log⁡(1−p)]⇒E[SL]=−[qlog⁡p+(1−q)log⁡(1−p)]S_L(p,y) = -\big[y\log p+(1-y)\log(1-p)\big] \Rightarrow \mathbb{E}[S_L] = -\big[q\log p+(1-q)\log(1-p)\big]SL​(p,y)=−[ylogp+(1−y)log(1−p)]⇒E[SL​]=−[qlogp+(1−q)log(1−p)]

ppp'ye göre türev: −q/p+(1−q)/(1−p)=0⇒q(1−p)=p(1−q)⇒p=q-q/p + (1-q)/(1-p)=0 \Rightarrow q(1-p)=p(1-q) \Rightarrow p=q−q/p+(1−q)/(1−p)=0⇒q(1−p)=p(1−q)⇒p=q. İkinci türev q/p2+(1−q)/(1−p)2>0q/p^2+(1-q)/(1-p)^2>0q/p2+(1−q)/(1−p)2>0, yani minimum. Fark, q∥pq\|pq∥p KL ıraksaması kadardır. Sayısal: q=0.7q=0.7q=0.7, p=0.5p=0.5p=0.5 → 0.6930.6930.693 nat; p=0.7p=0.7p=0.7 → 0.6110.6110.611; ceza 0.0820.0820.082.

Doğruluk (accuracy) neden proper değil

E[dog˘ruluk]=q⋅1[p≥0.5]+(1−q)⋅1[p<0.5]\mathbb{E}[\text{doğruluk}] = q\cdot\mathbb{1}[p\ge 0.5] + (1-q)\cdot\mathbb{1}[p<0.5]E[dog˘​ruluk]=q⋅1[p≥0.5]+(1−q)⋅1[p<0.5]

q=0.7q=0.7q=0.7 iken p=0.51p=0.51p=0.51 de p=0.999p=0.999p=0.999 de aynı beklenen skoru verir: 0.70.70.7. Skor, ppp'nin büyüklüğüne duyarsız; yalnız eşiğin hangi tarafında olduğuna bakıyor. Sonuç: doğruluğu maksimize etmek isteyen bir model için tek serbestlik eşiğin doğru tarafında olmaktır; 0.51 ile 1.0 arasında hiçbir teşvik yok. ppp'yi kalibre etmek, doğruluğu hiç değiştirmez.

Bu yüzden: doğruluk sıralama metriğidir, olasılık metriği değil. Aynı şey ROC-AUC için de geçerli — AUC, tahminlerin monoton dönüşümüne duyarsızdır. Kalibrasyon iddiası taşıyan hiçbir metrik monoton-dönüşüm-değişmez olamaz; kalibrasyon tam olarak "hangi monoton dönüşüm" sorusudur.

Dört model, aynı veri: doğru kalibre, aşırı dik, sabit, eşiklenmiş. Brier, ECE (üç farklı kutu sayısı), doğruluk — ve Murphy ayrışımı.

# test: python 3.13 · numpy 2.5.4
# PC'de çalıştır — gerekli: numpy
# Brier ayrışımı (reliability - resolution + uncertainty) ve ECE'nin oynanabilirliği.
import numpy as np

rng = np.random.default_rng(0)
n = 5000
x = rng.normal(0, 1, n)
q = 1 / (1 + np.exp(-2 * x))                 # gerçek olasılık (bilinen)
y = (rng.random(n) < q).astype(float)

modeller = {
    "A doğru kalibre": q,
    "B aşırı emin":   1 / (1 + np.exp(-4 * x)),          # aynı sıralama, dik eğim
    "C sabit 0.5":     np.full(n, 0.5),                  # hiç bilgi yok
    "D 0/1 tahmin":    np.where(q > 0.5, 0.95, 0.05),    # eşik + sahte güven
}
brier = lambda p: np.mean((p - y) ** 2)

def ece(p, b=10):
    kenar = np.linspace(0, 1, b + 1)
    idx = np.clip(np.digitize(p, kenar[1:-1]), 0, b - 1)
    return sum(abs(p[idx == k].mean() - y[idx == k].mean()) * (idx == k).mean()
               for k in range(b) if (idx == k).any())

print(f"{'model':18} {'Brier':>7} {'ECE10':>7} {'ECE50':>7} {'ECE=n':>7} {'doğruluk':>9}")
for ad, p in modeller.items():
    print(f"{ad:18} {brier(p):7.4f} {ece(p,10):7.4f} {ece(p,50):7.4f} {ece(p,n):7.4f} "
          f"{(np.round(p) == y).mean():9.3f}")

# --- Brier ayrışımı: 3 kutu, kutu ortalamasıyla (kimlik birebir)
p = modeller["B aşırı emin"]
kenar = np.array([0, 1/3, 2/3, 1.0])
idx = np.clip(np.digitize(p, kenar[1:-1]), 0, 2)
o = y.mean()
rel = res = 0.0
print("\nkutu   n     p_ort   o_ort")
for k in range(3):
    m = idx == k
    pk, ok = p[m].mean(), y[m].mean()
    rel += m.mean() * (pk - ok) ** 2
    res += m.mean() * (ok - o) ** 2
    print(f"{k:4d} {m.sum():4d} {pk:8.4f} {ok:8.4f}")
unc = o * (1 - o)
p_kutu = np.array([p[idx == k].mean() for k in idx])      # her noktayı kutu ortalamasıyla değiştir
print(f"reliability={rel:.4f}  resolution={res:.4f}  uncertainty={unc:.4f}")
print(f"rel - res + unc      = {rel-res+unc:.6f}")
print(f"Brier(kutu ortalaması) = {brier(p_kutu):.6f}")
print(f"ham Brier (kutu içi saçılma dahil) = {brier(p):.4f}")

# --- sıcaklık ölçekleme: iki sınıf, logit aralığı z
sig = lambda z: 1 / (1 + np.exp(-z))

ECE'nin altı sorunu ve yerine ne konur

ECE (expected calibration error) tanımı:

ECE=∑k=1Bnkn ∣pˉk−oˉk∣\text{ECE}=\sum_{k=1}^{B}\frac{n_k}{n}\,\big|\bar p_k-\bar o_k\big|ECE=k=1∑B​nnk​​​pˉ​k​−oˉk​​

pˉk\bar p_kpˉ​k​: kkk. kutudaki ortalama tahmin, oˉk\bar o_koˉk​: o kutudaki gerçek pozitif oran. Sezgisel olarak "güven ile doğruluk arasındaki ortalama mesafe".

Sorunlar

  1. Kutu seçimine bağımlı. Eşit genişlik mi, eşit kütle mi, kaç kutu? Aynı model 0.011 de 0.235 de çıkabilir (yukarıdaki tablo). Raporlanan ECE, kutu sayısı yazılmadan karşılaştırılamaz.
  2. Keskinliğe kör. Sabit 0.5 modeli 0.004 alıyor. ECE, "herkese aynı olasılığı veren" modeli ödüllendirir; böyle bir model karar için değersizdir.
  3. Proper değil. Skor kuralı olmadığı için ECE'yi doğrudan optimize etmek anlamsızdır; türevlenemez de. Eğitimde kullanılan kayıp (NLL) ile raporlanan metrik (ECE) farklı hedefleri ölçer.
  4. Kutu içini görmez. Bir kutuda 0.30 diyen model ile 0.70 diyen model aynı pˉ\bar ppˉ​'ye katkı verebilir; ECE ikisini ayırmaz. Sıralama bilgisi kutunun içinde kaybolur.
  5. Küçük örnekte yanlı. nkn_knk​ küçükse oˉk\bar o_koˉk​ gürültülüdür; ECE'nin beklenen değeri gerçek kalibrasyon hatasından sapar (yukarı yönlü yan). n=200n=200n=200'de 0.02'lik ECE "iyi" sayılmamalı; güven aralığı hesaplanmalı (bootstrap).
  6. Tanım çokluğu. "Top-label ECE" (yalnız en yüksek olasılıklı sınıf), "classwise ECE" (her sınıf için ikili kalibrasyon), "adaptive ECE" farklı şeyler ölçer. Hangi ECE olduğu yazılmadan sayı anlamsızdır.

Yerine ne konur

  • Ana metrik: NLL veya Brier. İkisi de strictly proper; kalibrasyonu ve keskinliği birlikte ödüllendirir, resolution farkını da içerir. Karşılaştırma için tek sayı gerekiyorsa bunlar.
  • Teşhis: reliability diagram + kutu başına nkn_knk​ yazdırın. Eğri köşegenden ne kadar ve hangi bölgede sapıyor?
  • Güven: bootstrap. Test setinden 1000 kez örnekleyip Brier/ECE dağılımını verin; iki model arasındaki farkın bu dağılımda nerede durduğunu görün.
  • Görev metriği: beklenen maliyet. Eşik kararı verilecekse, kalibre olasılıkları maliyet matrisiyle çarpıp beklenen maliyeti karşılaştırın. Bu, kalibrasyonu iş diline çeviren tek adım.

Sıcaklık ölçekleme: neden çalışır

Sinir ağları genelde aşırı emin (Guo ve ark., 2017): %95 der, doğruluğu %80'dir. En basit düzeltme, logitleri tek bir T>0T>0T>0 ile bölmek:

pi=exp⁡(zi/T)∑jexp⁡(zj/T)p_i=\frac{\exp(z_i/T)}{\sum_j\exp(z_j/T)}pi​=∑j​exp(zj​/T)exp(zi​/T)​

Üç özellik:

  • Argmax değişmez. zi/Tz_i/Tzi​/T sıralaması ziz_izi​ ile aynı; doğruluk ve AUC birebir korunur.
  • Tek parametre. TTT doğrulama setinde NLL minimize edilerek bulunur. Aşırı öğrenme riski minimaldir — 1 parametre, binlerce örnek.
  • Yön. T>1T>1T>1 olasılıkları 0.5'e çeker (yumuşatır), T<1T<1T<1 keskinleştirir. Yukarıdaki çıktıda logit farkı 4 iken T=4T=4T=4 olasılığı 0.982'den 0.731'e indiriyor.

Sıcaklık ölçekleme global bir düzeltmedir: tüm sınıflar için tek TTT. Sınıf bazlı kalibrasyon bozukluğu (bir sınıf sistematik olarak abartılıyorsa) düzelmez; o zaman sınıf başına sıcaklık veya Dirichlet kalibrasyonu gerekir.

Kalibrasyon dağılım kaymasında bozulur

Model eğitimde %50 pozitif görüp üretimde %10 görüyorsa, p(y∣x)p(y\mid x)p(y∣x) aynı kalsa bile p(y)p(y)p(y) değişir; modelin çıktısı artık kalibre değildir. Düzeltme, odds'u önceki oranıyla çarpmaktır:

logit⁡(pyeni)=logit⁡(peski)+log⁡πyeni/(1−πyeni)πeski/(1−πeski)\operatorname{logit}\big(p_{\text{yeni}}\big)=\operatorname{logit}\big(p_{\text{eski}}\big)+\log\frac{\pi_{\text{yeni}}/(1-\pi_{\text{yeni}})}{\pi_{\text{eski}}/(1-\pi_{\text{eski}})}logit(pyeni​)=logit(peski​)+logπeski​/(1−πeski​)πyeni​/(1−πyeni​)​

πeski=0.5\pi_{\text{eski}}=0.5πeski​=0.5, πyeni=0.1\pi_{\text{yeni}}=0.1πyeni​=0.1 için kayma log⁡(0.111/1)=−2.197\log(0.111/1)=-2.197log(0.111/1)=−2.197: 0.8 olasılığı logit⁡(0.8)=1.386\operatorname{logit}(0.8)=1.386logit(0.8)=1.386, yeni logit −0.811-0.811−0.811, yeni olasılık 0.308. Aynı model, aynı skor, farklı olasılık. Kalibrasyon eğitim dağılımına bağlıdır; dağılım değişince yeniden ölçülmelidir.

Platt ölçekleme ve izotonik regresyonu sıfırdan (karar skoru → olasılık), ayrı kalibrasyon setiyle; sonra iki klasik tuzağı say.

# test: python 3.13 · numpy 2.5.4 · scikit-learn 1.9.1
# PC'de çalıştır — gerekli: numpy, scikit-learn
# Kalibrasyon düzeltmesi: Platt (sigmoid) ve isotonic; sızıntı tuzağı ve varyans.
import numpy as np
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.svm import SVC
from sklearn.naive_bayes import GaussianNB
from sklearn.linear_model import LogisticRegression
from sklearn.isotonic import IsotonicRegression
from sklearn.metrics import brier_score_loss, roc_auc_score

X, y = load_breast_cancer(return_X_y=True)
Xtr, Xtmp, ytr, ytmp = train_test_split(X, y, test_size=.4, random_state=0, stratify=y)
Xcal, Xte, ycal, yte = train_test_split(Xtmp, ytmp, test_size=.5, random_state=0, stratify=ytmp)

def ece(p, y, b=10):
    idx = np.clip(np.digitize(p, np.linspace(0, 1, b + 1)[1:-1]), 0, b - 1)
    return sum(abs(p[idx == k].mean() - y[idx == k].mean()) * (idx == k).mean()
               for k in range(b) if (idx == k).any())

def rapor(ad, p):
    print(f"{ad:26} Brier={brier_score_loss(yte, p):.4f} ECE={ece(p, yte):.4f} "
          f"AUC={roc_auc_score(yte, p):.4f} doğruluk={(np.round(p) == yte).mean():.3f}")

def platt(z_kal, y_kal, z_test):
    m = LogisticRegression().fit(z_kal[:, None], y_kal)
    return m.predict_proba(z_test[:, None])[:, 1]

def izotonik(z_kal, y_kal, z_test):
    return IsotonicRegression(out_of_bounds="clip").fit(z_kal, y_kal).predict(z_test)

def dvm(m, X_):
    """Skoru log-odds ölçeğine getir: SVC'de karar fonksiyonu, NB'de log(p/(1-p))."""
    if hasattr(m, "decision_function"):
        return m.decision_function(X_)
    p = np.clip(m.predict_proba(X_)[:, 1], 1e-6, 1 - 1e-6)
    return np.log(p / (1 - p))

print(f"eğitim {len(ytr)}, kalibrasyon {len(ycal)}, test {len(yte)}")
for ad, temel in (("SVC", SVC(random_state=0)), ("GaussianNB", GaussianNB())):
    temel.fit(Xtr, ytr)
    ztr, zkal, zte = dvm(temel, Xtr), dvm(temel, Xcal), dvm(temel, Xte)
    rapor(f"{ad} ham sigmoid", 1 / (1 + np.exp(-zte)))
    rapor(f"{ad} + Platt", platt(zkal, ycal, zte))
    rapor(f"{ad} + isotonic", izotonik(zkal, ycal, zte))
    print()

# --- tuzak: kalibratörü fit ettiğin sette ECE ölçmek
svc = SVC(random_state=0).fit(Xtr, ytr)
ztr, zkal, zte = dvm(svc, Xtr), dvm(svc, Xcal), dvm(svc, Xte)
print("isotonic nerede fit edildi?   fit ECE   test ECE   test Brier")
for ad, zf, yf in (("eğitim seti (341)", ztr, ytr), ("ayrı set (114)", zkal, ycal)):
    iso = IsotonicRegression(out_of_bounds="clip").fit(zf, yf)
    print(f"  {ad:24} {ece(iso.predict(zf), yf):9.4f} {ece(iso.predict(zte), yte):10.4f} "
          f"{brier_score_loss(yte, iso.predict(zte)):12.4f}")

# --- küçük kalibrasyon setinde isotonic'in varyansı
print("\n60 örnekli kalibrasyon seti, 20 tekrar (test Brier ortalaması ± std)")
sonuc = {"Platt": [], "isotonic": []}
for s in range(20):
    idx = np.random.default_rng(s).choice(len(ytr), 60, replace=False)
    sonuc["Platt"].append(brier_score_loss(yte, platt(ztr[idx], ytr[idx], zte)))
    sonuc["isotonic"].append(brier_score_loss(yte, izotonik(ztr[idx], ytr[idx], zte)))
for k, v in sonuc.items():
    print(f"  {k:9} {np.mean(v):.4f} ± {np.std(v):.4f}")

Anlatım05 / 09

Pratik: kalibrasyonu karar maliyetine bağla

Görev. Kalibrasyonu "güzel grafik" olmaktan çıkarıp para cinsinden ölçün.

  1. load_breast_cancer üzerinde üç model eğitin: LogisticRegression, GaussianNB, SVC(kernel="rbf"). Eğitim/doğrulama/test üçe bölün (60/20/20).
  2. Üçünü de doğrulama setinde kalibre edin (Platt ve isotonic). Test setinde şu tabloyu üretin: Brier | NLL | ECE(10, eşit genişlik) | ECE(10, eşit kütle) | doğruluk.
  3. Maliyet senaryosu. Yanlış pozitif maliyeti 1, yanlış negatif maliyeti 5 (ıskalanan kanser pahalı). Kalibre olasılıklardan beklenen maliyeti en küçükleyen eşiği hesaplayın: t=cFPcFP+cFN=1/6≈0.167t=\frac{c_{FP}}{c_{FP}+c_{FN}}=1/6\approx0.167t=cFP​+cFN​cFP​​=1/6≈0.167. Bu eşiği kalibre ve kalibre olmayan skorlara uygulayın; test maliyetlerini karşılaştırın.
  4. Beklenen sonuç. Ham NB/SVC'de 0.167 eşiği yanlış yere düşer (skorlar olasılık ölçeğinde değil), maliyet yükselir. Kalibrasyondan sonra eşik anlam kazanır. Fark genelde 1-3 yanlış karar mertebesinde; veri küçük olduğu için tek koşuya güvenmeyin, 20 farklı bölmeyle ortalayın.
  5. Bootstrap. Her model için 1000 bootstrap örneklemiyle Brier'ın %95 aralığını verin. Aralıklar üst üste biniyorsa "A daha iyi" demeyin.

İpucu. CalibratedClassifierCV kullanacaksanız sklearn 1.6+ sürümünde ayrı kalibrasyon seti için FrozenEstimator(est) verip cv=None bırakın; eski cv="prefit" kaldırıldı. SVC(probability=True) de kullanımdan kaldırıldı (uyarı verir) — yerine CalibratedClassifierCV(SVC(), ensemble=False) var. Kod örneğinde bunu elle yaptık ki mekanizma görünsün.

Ek pratik. Aynı deneyi çok sınıflı bir problemde yapın (ör. load_digits, 10 sınıf): top-label ECE, sınıf başına ECE ve Brier. Tek bir sıcaklık parametresinin hangi sınıfları düzeltip hangilerini düzeltmediğini raporlayın.

Kontrol06 / 09

Bir modelin doğruluğu %90, ama sürekli 0.99 güvenle tahmin ediyor. Bu modelin Brier skoru ve ECE'si hakkında ne söylersiniz?

Cevabı göster

Brier yüksek çıkar (0.99 diyip %10 yanılırsa kabaca 0.1-0.15 mertebesi) ve ECE de yüksektir (~0.09): model aşırı emindir. Ama doğruluk iyi olduğu için 'model kötü' demek yanlış olur; sıralaması iyi, ölçeği bozuk. Doğru müdahale sıcaklık/Platt ölçeklemesi: doğruluk ve AUC değişmez, Brier ve ECE düşer. Eğer olasılıklar bir karar eşiğinde veya beklenen değer hesabında kullanılıyorsa bu düzeltme zorunludur.

Kontrol07 / 09

Tüm örneklerde p = 0.5 diyen bir model, dengeli bir test setinde ECE = 0 alıyor. Bu neden mümkün ve bu model neden yine de işe yaramaz? Hangi metrik bunu yakalar?

Cevabı göster

Dengeli sette gerçek pozitif oran 0.5 olduğu için tek kutuda |p̄ - ō| = |0.5 - 0.5| = 0; ECE tanımı yalnız bu farka baktığı için 0 çıkar. Model hiç bilgi taşımıyor (AUC 0.5, doğruluk 0.5) ama kalibre görünüyor; ECE keskinliği (resolution) ölçmez. Yakalayan metrik Brier'dir: 0.25, yani hiçbir şey öğrenmemiş modelin taban değeri. Murphy ayrışımında da resolution terimi 0 çıkar; asıl eksiklik oradadır.

Kontrol08 / 09

Sıcaklık ölçekleme doğruluğu ve AUC'yi neden değiştirmez, ama isotonic kalibrasyon AUC'yi neden değiştirebilir?

Cevabı göster

Sıcaklık ölçekleme p_i = softmax(z_i/T) biçiminde kesinlikle monoton bir dönüşümdür: z sıralaması korunur, dolayısıyla argmax (doğruluk) ve tüm eşik-tabanlı sıralama ölçütleri (AUC) birebir aynı kalır. Isotonic ise eşit skorlu noktaları aynı değere eşleyen, parçalı sabit, genişleyen bir fonksiyondur; sıralamayı eşitlikler lehine bozar, dolayısıyla AUC ve bazen doğruluk değişir. Pratik kural: sıralamayı korumak istiyorsanız monoton bir kalibratör (Platt/sıcaklık) kullanın.

Özet09 / 09
  • Proper skor kuralı, gerçek olasılığı bildirmeyi en kârlı yapan kuraldır; strictly proper ise tek optimum p=qp=qp=q.
  • Brier cezası tam olarak (p−q)2(p-q)^2(p−q)2; log loss cezası KL(q∥p)\mathrm{KL}(q\|p)KL(q∥p). İkisi de strictly proper.
  • Doğruluk ve AUC sıralama metrikleridir: monoton dönüşüme duyarsız, dolayısıyla kalibrasyon iddiası taşıyamaz.
  • ECE proper değil: kutu sayısına bağlı (aynı model 0.011–0.235), keskinliğe kör (sabit 0.5 modeli 0 kusur alır), kutu içini görmez, küçük örnekte yanlı.
  • Murphy ayrışımı: Brier=reliability−resolution+uncertainty\text{Brier}=\text{reliability}-\text{resolution}+\text{uncertainty}Brier=reliability−resolution+uncertainty (kutu ortalamalarıyla birebir). Teşhis için kullan, kayıp olarak değil.
  • Düzeltme: Platt (2 parametre, monoton, AUC korur) veya isotonic (esnek, az veride varyanslı, AUC bozar). Sıcaklık ölçekleme çok sınıflı ağlarda tek parametreli, doğruluğu koruyan çözüm.
  • Kalibrasyon ayrı bir sette fit edilir; fit edildiği sette ECE ölçmek tautolojidir (isotonic'te tam 0).
  • Kalibrasyon dağılıma bağlıdır: önceki oran değişince odds düzeltmesi gerekir.
